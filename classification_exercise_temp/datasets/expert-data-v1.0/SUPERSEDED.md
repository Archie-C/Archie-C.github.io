# Superseded dataset

Do not use `expert-data-v1.0` as the student release. A subsequent scope audit
found 54 ordinary flight observations whose angle of attack exceeded the
calibrated 35° envelope. They were valid simulator states, but outside the
specified dataset scope. The original files and manifest are retained unchanged
for provenance and historical replay. Use the corrected `expert-data-v1.1`
dataset instead.
