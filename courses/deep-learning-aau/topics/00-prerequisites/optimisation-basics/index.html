Optimisation Basics.

Optimisation is the computational heart of machine learning. Training a neural network means searching for a set of parameters that minimises a scalar loss function, converting our mathematical objective into a concrete, solvable algorithm.

What this note covers

  • Mathematical formulation of optimisation problems
  • Local vs. global extrema and critical (stationary) points
  • Convex sets, convex functions, and the guarantees of convexity
  • Constrained optimisation and the method of Lagrange Multipliers
  • A Python implementation of Gradient Descent on a quadratic landscape

For a detailed treatment, see Chapter 7 of Mathematics for Machine Learning.

Optimization Problems

In continuous optimisation, we want to find the value of a parameter vector $\mathbf{x} \in \mathbb{R}^d$ that minimises a real-valued objective function $f(\mathbf{x})$:

$$ \min_{\mathbf{x}} f(\mathbf{x}) \quad \text{subject to} \quad \mathbf{x} \in \mathcal{X} $$

where $\mathcal{X} \subseteq \mathbb{R}^d$ is the constraint set. If $\mathcal{X} = \mathbb{R}^d$, the problem is unconstrained optimisation. If $\mathcal{X}$ is a proper subset defined by equality or inequality equations, it is a constrained optimisation problem.

Note that maximising a function $h(\mathbf{x})$ is mathematically equivalent to minimising $-h(\mathbf{x})$, so we can frame all problems as minimisation without loss of generality.

Stationary Points and Extrema

A point $\mathbf{x}^*$ is a local minimum of $f$ if there exists a small neighborhood $\mathcal{U}$ around $\mathbf{x}^*$ such that $f(\mathbf{x}^*) \le f(\mathbf{x})$ for all $\mathbf{x} \in \mathcal{U}$. It is a global minimum if $f(\mathbf{x}^*) \le f(\mathbf{x})$ for all possible $\mathbf{x} \in \mathcal{X}$.

For a continuously differentiable function, a point where the gradient is zero is called a critical point or stationary point:

$$ \nabla f(\mathbf{x}^*) = \mathbf{0} $$

We classify stationary points using the second derivative matrix, the Hessian $\mathbf{H}(\mathbf{x}) \in \mathbb{R}^{d \times d}$, defined by $\mathbf{H}_{ij}(\mathbf{x}) = \frac{\partial^2 f(\mathbf{x})}{\partial x_i \partial x_j}$:

  • Local Minimum: If $\mathbf{H}(\mathbf{x}^*)$ is positive definite ($\mathbf{H} \succ 0$, all eigenvalues are strictly positive), then the function curves upwards in every direction, confirming a local minimum.

  • Local Maximum: If $\mathbf{H}(\mathbf{x}^*)$ is negative definite ($\mathbf{H} \prec 0$, all eigenvalues are strictly negative), the function curves downwards, indicating a local maximum.

  • Saddle Point: If $\mathbf{H}(\mathbf{x}^*)$ is indefinite (having both positive and negative eigenvalues), the function curves upwards in some directions and downwards in others.

Convexity

In deep learning, we often work with non-convex loss landscapes which can contain many local minima and saddle points. However, understanding convexity is fundamental because it provides the theoretical boundary where optimisation becomes globally solvable.

Convex Sets

A set $\mathcal{C}$ is convex if the line segment connecting any two points in the set lies entirely within $\mathcal{C}$:

$$ \forall \mathbf{x}, \mathbf{y} \in \mathcal{C}, \quad \theta \mathbf{x} + (1 - \theta)\mathbf{y} \in \mathcal{C} \quad \text{for all } \theta \in [0, 1] $$

Let's break down this mathematical definition to see what it actually means:

  • The Universal Quantifier ($\forall$): The symbol $\forall$ means "for all" or "for every". This indicates that the rule must hold true no matter which pair of points you pick inside the set.

  • The Set Membership ($\in$): The symbol $\in$ means "is an element of" or "belongs to". So, $\mathbf{x}, \mathbf{y} \in \mathcal{C}$ means we choose any two points $\mathbf{x}$ and $\mathbf{y}$ that are inside the set $\mathcal{C}$.

  • The Mixture Parameter ($\theta$): The parameter $\theta$ (the Greek letter theta) acts like a slider or a percentage regulator between $0$ and $1$ (representing $0\%$ to $100\%$).

  • The Weighted Blend ($\theta \mathbf{x} + (1 - \theta)\mathbf{y}$): This expression calculates a weighted average of our two points. If you set $\theta = 1$, the expression evaluates to $\mathbf{x}$. If you set $\theta = 0$, it evaluates to $\mathbf{y}$. If you choose $\theta = 0.5$, it evaluates to the exact midpoint between them. By sweeping $\theta$ from $0$ to $1$, the expression traces out every single point on the straight line segment connecting $\mathbf{y}$ to $\mathbf{x}$.

Combining these parts, the condition $\theta \mathbf{x} + (1 - \theta)\mathbf{y} \in \mathcal{C}$ guarantees that the entire straight line connecting any two points in the set remains completely inside the set. Visually, a circle, a solid sphere, or a triangle are convex sets. Conversely, a star shape or a crescent moon is non-convex: if you connect the two outer tips of a crescent moon with a straight line, the middle of that line passes through the empty space outside the moon.

Convex Functions

A function $f: \mathcal{C} \to \mathbb{R}$ is convex if the line segment connecting any two points on the function's graph lies on or above the graph itself. Mathematically, this is written as:

$$ f(\theta \mathbf{x} + (1 - \theta)\mathbf{y}) \le \theta f(\mathbf{x}) + (1 - \theta)f(\mathbf{y}) \quad \text{for all } \theta \in [0, 1] $$

This inequality looks intimidating, but it is much easier to read when we compare the two sides:

  • Left-Hand Side (Function of the Blend): The expression $f(\theta \mathbf{x} + (1 - \theta)\mathbf{y})$ tells us to first blend the inputs $\mathbf{x}$ and $\mathbf{y}$ (finding a point on the line segment between them, like their midpoint), and then evaluate the function's height at that blended input. This represents the actual depth or height of the function curve.

  • Right-Hand Side (Blend of the Functions): The expression $\theta f(\mathbf{x}) + (1 - \theta)f(\mathbf{y})$ tells us to find the heights of the function at the two endpoints, $f(\mathbf{x})$ and $f(\mathbf{y})$, and then take the weighted average of those heights. This represents the height of the straight secant line (or chord) connecting the two points on the graph.

This mathematically guarantees that the function behaves like a bowl, curving upwards or remaining flat, but never bowing downwards.

First-Order Characterization (Slopes & Tangents)

If a function is differentiable, we can characterize its convexity using its first derivative (the gradient). A differentiable function $f$ is convex if and only if:

$$ f(\mathbf{y}) \ge f(\mathbf{x}) + \nabla f(\mathbf{x})^\top (\mathbf{y} - \mathbf{x}) $$

This formula relates the true shape of the function to its tangent planes. Let's break down the individual terms:

  • $f(\mathbf{y})$: The actual value of the function at some target destination point $\mathbf{y}$.

  • $f(\mathbf{x})$: The value of the function at our current starting point $\mathbf{x}$.

  • $\nabla f(\mathbf{x})$: The gradient vector at $\mathbf{x}$. This represents the slope of the function and the direction of steepest ascent at our current position.

  • $(\mathbf{y} - \mathbf{x})$: The displacement vector pointing directly from our starting point $\mathbf{x}$ to our target destination $\mathbf{y}$.

  • $\nabla f(\mathbf{x})^\top (\mathbf{y} - \mathbf{x})$: This is the vector dot product of the slope and the displacement. It calculates how much the function's height would change if we walked from $\mathbf{x}$ to $\mathbf{y}$ along a perfectly flat, straight ramp that matches the local slope at $\mathbf{x}$. This is the linear approximation of the change.

The entire right-hand side $f(\mathbf{x}) + \nabla f(\mathbf{x})^\top (\mathbf{y} - \mathbf{x})$ is therefore the mathematical formula for the tangent line (in 1D) or tangent plane (in higher dimensions) touching the function at point $\mathbf{x}$.

The inequality $\ge$ states that the actual function value $f(\mathbf{y})$ is always at least as high as this tangent plane's prediction. Visually, if you place a flat piece of cardboard tangent to any point on a bowl, the bowl curves upwards away from the cardboard, staying entirely above it. The gradient's linear approximation acts as a global underestimator of the function.

Second-Order Characterization (Curvature)

If a function is twice-differentiable, we can look at its curvature. A twice-differentiable function $f$ is convex if and only if its Hessian matrix is positive semi-definite everywhere in its domain:

$$ \mathbf{H}(\mathbf{x}) \succeq 0 $$

Here is what this means in plain terms:

  • The Hessian Matrix ($\mathbf{H}(\mathbf{x})$): The Hessian is a matrix of second-order partial derivatives. It measures how the slopes are changing in every possible direction, representing the multi-dimensional curvature of the function.

  • Positive Semi-Definite ($\succeq 0$): The symbol $\succeq 0$ applied to a matrix means it is positive semi-definite. In one dimension, this is equivalent to the scalar second derivative being non-negative ($f''(x) \ge 0$), which means the slope is either constant (a flat line) or increasing (curving upwards). In multiple dimensions, it means that for any direction vector $\mathbf{v}$, the second derivative along that direction, given by the quadratic form $\mathbf{v}^\top \mathbf{H}(\mathbf{x})\mathbf{v}$, is non-negative ($\ge 0$).

This condition guarantees that no matter which direction you walk, and no matter where you are on the function, the landscape is either flat or curving upwards like a valley. It never curves downwards like a dome.

guarantees of convex optimisation

Convex functions possess two crucial properties that make them highly desirable:

1. Any local minimum is guaranteed to be a global minimum.

2. The first-order condition $\nabla f(\mathbf{x}^*) = \mathbf{0}$ is both necessary and sufficient for global optimality.

Gradient Descent Trajectory

To find local minima, we start at a point $\mathbf{x}^{(0)}$ and iteratively step in the direction of steepest descent, which is the negative gradient direction:

$$ \mathbf{x}^{(t+1)} = \mathbf{x}^{(t)} - \alpha \nabla f(\mathbf{x}^{(t)}) $$

where $\alpha > 0$ is the learning rate (or step size).

Constrained Optimisation & Lagrange Multipliers

In many setups, we need to optimize an objective $f(\mathbf{x})$ while satisfying constraints. Consider a problem with a single equality constraint:

$$ \min_{\mathbf{x}} f(\mathbf{x}) \quad \text{subject to} \quad g(\mathbf{x}) = 0 $$

At the optimal point $\mathbf{x}^*$, the contour line of the objective function $f(\mathbf{x})$ must run tangent to the constraint curve $g(\mathbf{x}) = 0$. If they were not tangent, we could slide along the constraint to find a lower value of $f$. Since their contours are tangent, their normal vectors—represented by the gradients—must be parallel (collinear) at $\mathbf{x}^*$:

$$ \nabla f(\mathbf{x}^*) = \lambda \nabla g(\mathbf{x}^*) $$

where the scaling constant $\lambda \in \mathbb{R}$ is the Lagrange multiplier.

We compile this geometric requirement into a single helper function, the Lagrangian:

$$ \mathcal{L}(\mathbf{x}, \lambda) = f(\mathbf{x}) - \lambda g(\mathbf{x}) $$

To find the optimal solution, we search for the critical points of the Lagrangian where the gradients with respect to both the parameters $\mathbf{x}$ and the multiplier $\lambda$ vanish:

$$ \nabla_{\mathbf{x}} \mathcal{L}(\mathbf{x}^*, \lambda^*) = \nabla f(\mathbf{x}^*) - \lambda^* \nabla g(\mathbf{x}^*) = \mathbf{0} $$

$$ \frac{\partial \mathcal{L}}{\partial \lambda} = -g(\mathbf{x}^*) = 0 $$

Solving this system of $d + 1$ equations yields the constrained optimum $\mathbf{x}^*$ (and the corresponding multiplier $\lambda^*$).

Implementation: Gradient Descent

Below is a clean Python script implementing Gradient Descent on our 2D quadratic landscape. It records the trajectory steps so you can inspect how the convergence rate behaves numerically.

def grad_descent_2d(
    start_x: float, start_y: float,
    alpha: float, gamma: float,
    num_steps: int
) -> list[tuple[float, float]]:
    """
    Runs gradient descent on the function:
    f(x1, x2) = 0.5 * (x1^2 + gamma * x2^2)
    Gradient is:
    grad_f(x1, x2) = [x1, gamma * x2]
    """
    x1, x2 = start_x, start_y
    path = [(x1, x2)]
    
    for _ in range(num_steps):
        # Compute gradient components
        grad_x1 = x1
        grad_x2 = gamma * x2
        
        # Apply update
        x1 = x1 - alpha * grad_x1
        x2 = x2 - alpha * grad_x2
        path.append((x1, x2))
        
    return path

if __name__ == "__main__":
    alpha = 0.2
    gamma = 4.0
    start_x1, start_x2 = 3.0, 3.0
    
    trajectory = grad_descent_2d(start_x1, start_x2, alpha, gamma, 10)
    print("Step-by-step optimization path:")
    for t, pt in enumerate(trajectory):
        f_val = 0.5 * (pt[0]**2 + gamma * pt[1]**2)
        print(f"  Step {t:02d}: x = [{pt[0]:.4f}, {pt[1]:.4f}]ᵀ, f(x) = {f_val:.4f}")
