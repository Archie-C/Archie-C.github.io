Error surfaces and gradient descent.

Once we have chosen a model and a loss function, we need a way to find suitable values for its parameters.

What this note covers

  • Error surfaces and stationary points
  • Gradients and the direction of steepest descent
  • Gradient descent and the learning rate
  • Updating several parameters at once
  • Limitations of gradient descent

Error surfaces

In the previous topic, we built neural networks and chose loss functions for their predictions. Training means finding parameter values that make the loss small. We can collect the weights and biases into a vector $\mathbf{w}$ and write the loss as $E(\mathbf{w})$, keeping the training data fixed.

It is useful to distinguish the input space, where each point is an input $\mathbf{x}$, from the parameter space, where each point is a choice of $\mathbf{w}$. When we evaluate a trained model on different inputs, we move through input space while keeping the parameters fixed. When we train the model, we instead change the parameters and evaluate the resulting predictions on the fixed training data.

Each point in parameter space therefore corresponds to one setting of the model's weights and biases and has an associated loss. The graph of that loss against the parameters is called an error surface. Training can be thought of as looking for a low point on this surface. A real network can have many thousands of parameters, so we cannot usually draw the whole surface, but a two-parameter example lets us see the idea.

Let's consider a model with just two parameters:

$$E(w_1,w_2)=(w_1-2)^2+4(w_2+1)^2.$$

Both terms are non-negative, so the smallest possible loss is zero. This occurs when $w_1=2$ and $w_2=-1$, giving the global minimum $\mathbf{w}^*=(2,-1)^\top$. For example, at $(w_1,w_2)=(0,0)$ the loss is $4+4=8$. Changing the parameter vector changes our position on the surface and the height tells us the resulting loss.

We can also represent the surface using a contour plot. A contour joins parameter values with the same loss, just as a contour on a map joins points at the same height. For instance, the contour for loss $4$ satisfies $(w_1-2)^2+4(w_2+1)^2=4$. It passes through $(4,-1)$ and $(2,0)$: both have the same loss even though their parameters differ.

Looking down on the surface gives the elliptical contours below. They are narrower in the $w_2$ direction because changing $w_2$ by the same amount as $w_1$, starting from the minimum, increases the loss four times as much. The centre of the contours is the bottom of the bowl.

At a differentiable stationary point, all first partial derivatives are zero, so $\nabla E(\mathbf{w})=\mathbf{0}$. The surface is locally flat to first order at such a point. This tells us where a differentiable minimum may occur, but it does not by itself tell us whether we have found a minimum.

A local minimum has loss no greater than points sufficiently close to it. A global minimum has loss no greater than any point in the parameter space. Every global minimum is also a local minimum, but a local minimum need not be the lowest point on the whole surface. Similarly, a local maximum has loss no smaller than nearby points. A stationary point need not be either: at a saddle point the surface rises in some directions and falls in others.

To see the distinction, consider $E(w)=(w^2-1)^2$. Differentiating and setting the result to zero gives:

$$\frac{dE}{dw}=4w(w^2-1)=0 \qquad\Longrightarrow\qquad w=-1,\;0,\;1.$$

The loss is zero at $w=-1$ and $w=1$. Since it is a square, it cannot be negative, so both are global minima. At $w=0$ the loss is $1$, and moving a small distance in either direction makes it smaller. This point is a local maximum, despite also having a zero derivative.

Now consider $f(w_1,w_2)=w_1^2-w_2^2$. Its gradient $(2w_1,-2w_2)^\top$ is zero at the origin. If we hold $w_2=0$, then $f=w_1^2$, which rises as we move away from the origin. If we instead hold $w_1=0$, then $f=-w_2^2$, which falls. The origin is therefore a saddle point: whether the function rises or falls depends on the direction we choose.

A function is convex if, between any two points, its graph lies on or below the straight line joining their heights. Any local minimum of a convex function is also global: there cannot be a separate, lower valley that is hidden beyond an intervening rise. A convex function can still have more than one global minimum, for example along a flat region.

The quadratic bowl above is convex. The double well is not: between its two minima, the graph rises above the line joining them. Neural network losses are generally non-convex because predictions depend on parameters through compositions of layers and nonlinear activations. As a result, their error surfaces can contain multiple valleys and stationary points, and finding a low point does not automatically tell us that it is the lowest one.

Gradients and steepest descent

For a scalar loss with $M$ parameters, the gradient collects the partial derivatives:

$$\nabla E(\mathbf{w})=\begin{pmatrix}\frac{\partial E}{\partial w_1}\\\vdots\\\frac{\partial E}{\partial w_M}\end{pmatrix}.$$

Each component tells us how the loss changes when we vary that parameter locally, holding the others fixed. A positive partial derivative means that a small increase in that parameter increases the loss; a negative derivative means that a small increase decreases it. The magnitude tells us how sensitive the loss is to that change.

In an update we may change several parameters at once. For a small displacement $\Delta\mathbf{w}$, a first-order Taylor approximation combines their effects:

$$E(\mathbf{w}+\Delta\mathbf{w})\approx E(\mathbf{w})+\nabla E(\mathbf{w})^\top\Delta\mathbf{w}.$$

The dot product adds the contribution from each parameter: $\nabla E(\mathbf{w})^\top\Delta\mathbf{w}=\sum_{j=1}^M (\partial E/\partial w_j)\Delta w_j$. It approximates the change in loss, with the derivatives evaluated at the starting point $\mathbf{w}$. We can use it to ask which small displacement reduces the loss most.

Suppose we fix the displacement's length at $\epsilon>0$ and write $\Delta\mathbf{w}=\epsilon\mathbf{u}$, where $\|\mathbf{u}\|=1$. The approximate change is then:

$$\Delta E\approx\epsilon\nabla E(\mathbf{w})^\top\mathbf{u}=\epsilon\|\nabla E(\mathbf{w})\|\cos\theta.$$

Here $\theta$ is the angle between the gradient and the displacement. Because $\mathbf{u}$ has length one, changing its direction changes $\cos\theta$ but not the length of our step. For a nonzero gradient, the approximate change is largest when $\cos\theta=1$, so $\mathbf{u}$ points along the gradient. It is smallest when $\cos\theta=-1$, so $\mathbf{u}$ points in the opposite direction. The direction of steepest local decrease is therefore:

$$\mathbf{u}=-\frac{\nabla E(\mathbf{w})}{\|\nabla E(\mathbf{w})\|}.$$

Along a contour the loss does not change locally, so a tangent displacement has zero dot product with the gradient. The gradient is therefore perpendicular to the contour and points towards increasing loss; the negative gradient points towards decreasing loss. On these elliptical contours, the negative gradient does not generally point directly at the minimum. It points in the direction that decreases the loss most quickly at the current point. As we move, that direction can change. In the figure, try moving the selected point to the centre. At the minimum the gradient is zero, so neither arrow has a direction.

There is an important qualification: this is a local result. The Taylor approximation uses the gradient at the starting point, but the gradient can change as we move and the surface curves. A direction that gives the greatest decrease for a very small step does not necessarily lead to the lowest loss after a large step.

The gradient descent algorithm

Some loss functions can be minimised analytically, but for a neural network this is generally unavailable or impractical. Instead, we can start with an initial parameter vector and repeatedly take a small step in the negative gradient direction:

$$\boxed{\mathbf{w}_{t+1}=\mathbf{w}_t-\eta\nabla E(\mathbf{w}_t)}$$

Here $\mathbf{w}_t$ is the parameter vector at iteration $t$, $\nabla E(\mathbf{w}_t)$ is the gradient evaluated at that vector, and $\eta>0$ is the learning rate. We subtract the gradient because it points uphill. After taking a step, we calculate a new gradient at the new parameter vector and use that for the next step.

The update scales the negative gradient rather than normalising it. This means that the step length is $\eta\|\nabla E(\mathbf{w}_t)\|$: it depends on both the learning rate and the magnitude of the gradient. In a steep region the same learning rate gives a larger step than in a flat region.

We need a rule for when to stop. For example, we might stop after a chosen number of iterations or when the gradient is sufficiently small. A small gradient tells us that the surface is locally flat, but, as we saw above, it does not establish that we have found a global minimum.

    Update w ← w − η∇E(w)

Worked example

Consider $E(w)=(w-3)^2$. The loss is zero at $w=3$ and positive elsewhere, so we know the minimum in advance. This makes it useful for checking what the updates do. Its derivative is $dE/dw=2(w-3)$, giving the update:

$$w_{t+1}=w_t-2\eta(w_t-3).$$

If $w$ is below $3$, the derivative is negative, so subtracting it increases $w$. If $w$ is above $3$, the derivative is positive, so the update decreases $w$. Let's start from $w_0=0$ with $\eta=0.1$. At the starting point the derivative is $-6$, so our first step adds $0.6$ to the parameter. Recalculating at each new point gives:

$$\begin{aligned}w_1&=0-0.2(0-3)=0.6,\\w_2&=0.6-0.2(0.6-3)=1.08,\\w_3&=1.08-0.2(1.08-3)=1.464.\end{aligned}$$

The learning rate

The learning rate controls how far we move for a given gradient. For the same quadratic, subtracting $3$ from both sides of the update gives:

$$w_{t+1}-3=(1-2\eta)(w_t-3).$$

The quantity $w_t-3$ is the signed distance from the minimum: it is negative to the left and positive to the right. The equation says that each iteration multiplies this signed distance by $1-2\eta$. Repeating the update gives:

$$w_t-3=(1-2\eta)^t(w_0-3).$$

For a starting point away from the minimum, the distance approaches zero precisely when the magnitude of the multiplier is less than one. Solving that condition gives:

$$|1-2\eta|<1 \quad\Longleftrightarrow\quad -1<1-2\eta<1 \quad\Longleftrightarrow\quad 0<\eta<1.$$

If the multiplier is positive, the iterates stay on the same side of the minimum. If it is negative, their sign alternates, so they cross the minimum at every step. Its magnitude determines whether these distances shrink, stay the same, or grow:

  • $\eta=0.1$: steady convergence from the same side.
  • $\eta=0.5$: the minimum is reached in one step.
  • $\eta=0.6$: oscillations decrease in size.
  • $\eta=1.0$: the iterates oscillate without converging.
  • $\eta=1.1$: the oscillations grow and the iterates diverge.

For example, with $\eta=0.6$ the multiplier is $-0.2$: each update crosses the minimum and leaves one fifth of the previous distance. With $\eta=1.1$ it is $-1.2$, so each crossing takes the parameter further away. At $\eta=1$ the multiplier is $-1$; starting away from the minimum, the two distances repeat indefinitely.

This range is specific to $E(w)=(w-3)^2$. Changing the curvature of the loss changes the gradient at a given distance from the minimum, and therefore changes the suitable learning rates. The condition $0<\eta<1$ is not a universal rule. A learning rate that works for one loss may be too large for another.

Gradient descent in multiple dimensions

Let's return to the two-parameter quadratic. Differentiating with respect to each parameter gives:

$$\nabla E(\mathbf{w})=\begin{pmatrix}2(w_1-2)\\8(w_2+1)\end{pmatrix}.$$

Starting at $\mathbf{w}_0=(0,0)^\top$ with $\eta=0.1$, the first gradient and update are:

$$\nabla E(\mathbf{w}_0)=\begin{pmatrix}-4\\8\end{pmatrix},\qquad \mathbf{w}_1=\begin{pmatrix}0\\0\end{pmatrix}-0.1\begin{pmatrix}-4\\8\end{pmatrix}=\begin{pmatrix}0.4\\-0.8\end{pmatrix}.$$

Evaluating the gradient again at each new point gives:

$$\begin{aligned}\mathbf{w}_2&=\begin{pmatrix}0.4\\-0.8\end{pmatrix}-0.1\begin{pmatrix}-3.2\\1.6\end{pmatrix}=\begin{pmatrix}0.72\\-0.96\end{pmatrix},\\[4pt]\mathbf{w}_3&=\begin{pmatrix}0.72\\-0.96\end{pmatrix}-0.1\begin{pmatrix}-2.56\\0.32\end{pmatrix}=\begin{pmatrix}0.976\\-0.992\end{pmatrix}.\end{aligned}$$

At the starting point, the first gradient component is negative and the second is positive. Subtracting them therefore increases $w_1$ and decreases $w_2$, moving both towards their values at the minimum. Both components are updated simultaneously using the gradient at the current point; we do not use the new $w_1$ to calculate the $w_2$ part of the same update.

Writing the update component by component makes the different rates of change clearer:

$$\begin{aligned}w_{1,t+1}-2&=(1-2\eta)(w_{1,t}-2),\\w_{2,t+1}+1&=(1-8\eta)(w_{2,t}+1).\end{aligned}$$

With $\eta=0.1$, the first signed distance is multiplied by $0.8$ and the second by $0.2$ at each step. So $w_2$ approaches its optimal value more quickly in this example, and the trajectory turns as the two gradient components change. The larger curvature in the $w_2$ direction gives a larger gradient for the same distance from its optimum. It also means that a learning rate suitable for one direction may be too large for another.

Limitations of gradient descent

Gradient descent gives us a way to search for parameters with a small loss, but the result depends on the surface and on our choices. For a general non-convex loss, following the local gradient does not guarantee a global minimum. Different initial parameters can lead the updates into different parts of the surface and towards different solutions.

Progress can also be slow in a flat region: when the gradient is small, the update is small even if the loss is still high. At a stationary point the gradient descent update is zero, but that point could be a maximum or saddle rather than a minimum. A small gradient alone does not tell us what kind of point we have reached.

The learning rate matters too. A small value can make progress slow, whereas a large value can make us overshoot, oscillate or diverge. Finally, when the loss is calculated over a large training dataset, calculating its gradient using every data point can be computationally expensive at each update. In the next note we will consider how the data used for each update affects this cost.

Summary

An error surface describes how loss changes as we vary model parameters. The gradient points towards the steepest local increase, so gradient descent repeatedly moves in the opposite direction. The learning rate and the shape of the surface affect the resulting trajectory.
