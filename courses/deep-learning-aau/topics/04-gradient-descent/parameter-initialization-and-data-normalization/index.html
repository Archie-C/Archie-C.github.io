Parameter initialisation and data normalisation.

How do the starting parameters and the scales of input features influence optimisation?

What this note covers

  • Initial values, symmetry and signal propagation
  • Xavier and He initialisation
  • Feature scaling, conditioning and standardisation
  • Using normalisation in a prediction pipeline

Why does initialisation matter?

The optimisation methods in the previous notes need somewhere to start. Given an initial parameter vector $\mathbf w_0$, ordinary gradient descent repeatedly evaluates the gradient and updates the parameters:

$$\mathbf w_{t+1}=\mathbf w_t-\eta\nabla E(\mathbf w_t).$$

The initial values determine the network's first predictions and loss, but also the intermediate activations from which gradients are calculated. They can affect the size of updates, their stability and the speed of training. On a non-convex loss surface, the starting position can also influence which region is explored and which solution is eventually found.

Consider a particularly simple non-convex loss:

$$E(w)=(w^2-1)^2,\qquad E'(w)=4w(w^2-1),\qquad E''(w)=12w^2-4.$$

The stationary points are $-1$, $0$ and $1$. At $\pm1$ the loss is zero and the second derivative is positive, so both are minima. At zero the second derivative is negative: it is a local maximum. Nevertheless, starting exactly at zero gives a zero gradient and ordinary gradient descent never moves. Starting on either side typically leads towards a different minimum when the learning rate is suitably small. Large steps can behave differently. This one-dimensional example illustrates sensitivity to the start; a neural network's loss surface is much more complicated.

Symmetry breaking

Randomness has another purpose beyond choosing a starting location. Consider one input, two hidden units and one output:

$$h_1=\phi(w_1x+b_1),\quad h_2=\phi(w_2x+b_2),\quad y=v_1h_1+v_2h_2+c.$$

If $w_1=w_2$, $b_1=b_2$ and $v_1=v_2$, both hidden units compute the same function. For one example with $E=\tfrac12(y-t)^2$, the chain rule gives

$$\frac{\partial E}{\partial v_i}=(y-t)h_i,\quad \frac{\partial E}{\partial w_i}=(y-t)v_i\phi'(w_ix+b_i)x,\quad \frac{\partial E}{\partial b_i}=(y-t)v_i\phi'(w_ix+b_i).$$

At identical parameters, corresponding gradients are identical. The same holds after summing over a batch. With the same update rule and optimiser state, the units remain identical after each update: they cannot learn different representations, and effectively act like one unit with a combined output weight. Randomly choosing distinct weights generally breaks this symmetry, so their responses and gradients can differ.

This does not mean every zero is forbidden. Biases are often set to zero while weights are random; randomly choosing only some parameters can suffice, depending on the architecture. A single-layer model can also learn from zero initialisation when its gradients are informative. The issue is a symmetry that keeps distinct trainable units identical, not the number zero by itself.

Initialisation scale and signal propagation

Breaking symmetry is not sufficient: the size of the random weights matters too. For unit $i$ in layer $l$, write

$$a_i^{(l)}=\sum_{j=1}^{M}w_{ij}^{(l)}z_j^{(l-1)}+b_i^{(l)},\qquad z_i^{(l)}=\phi(a_i^{(l)}).$$

The pre-activation $a_i^{(l)}$ combines the previous activations using the incoming weights, then adds a bias. The activation function transforms this sum into the signal passed onwards. If weights are very small, signals can shrink repeatedly through layers; depending on the activation and architecture, gradients can also become weak. Very large weights can instead amplify signals and destabilise computations.

Activation functions respond differently. Sigmoid and tanh saturate at large positive or negative inputs, where their derivatives are close to zero. ReLU has no upper bound on its positive side and derivative one there, but sends negative inputs to zero. Thus large values need not saturate positive ReLU units, and can instead grow across layers. Initialisation aims both to break symmetry and to keep signals at useful scales. Forward activations and backward gradients are different quantities: controlling one does not automatically control the other. Section 8 will develop the backward calculations.

Xavier/Glorot initialisation

How should the scale depend on the number of connections? Let $n_{\mathrm{in}}$ be the number entering each unit (fan-in) and $n_{\mathrm{out}}$ the number leaving it (fan-out). Consider a linear layer without biases. If weights are independent, zero mean, have common variance $\sigma_w^2$, and are independent of the inputs, cross terms vanish:

$$\mathbb E[a_i^2]=\sum_{j=1}^{n_{\mathrm{in}}}\mathbb E[w_{ij}^2]\mathbb E[z_j^2]\approx n_{\mathrm{in}}\sigma_w^2\mathbb E[z_j^2].$$

The approximation assumes similar input second moments. The pre-activation has zero mean over the random weights, so its second moment is also its variance in this calculation. A forward factor near one suggests $\sigma_w^2\approx1/n_{\mathrm{in}}$. A corresponding simplified backward argument involves fan-out and suggests $1/n_{\mathrm{out}}$. Glorot initialisation compromises between these requirements:

$$\boxed{\operatorname{Var}(w_{ij})=\frac{2}{n_{\mathrm{in}}+n_{\mathrm{out}}}}. $$

For a Gaussian, $w_{ij}\sim\mathcal N(0,2/(n_{\mathrm{in}}+n_{\mathrm{out}}))$, where the second argument is variance. For a uniform distribution $\mathcal U(-a,a)$, the variance is $a^2/3$, so the equivalent choice is

$$a=\sqrt{\frac{6}{n_{\mathrm{in}}+n_{\mathrm{out}}}}.$$

This analysis motivates a useful scale; it does not guarantee constant variance in a nonlinear network. It is associated with linear and tanh-like activations, especially where tanh operates approximately linearly. Saturation and changing statistics can violate the assumptions. ReLU removes negative signals and motivates a different scale.

Worked example

For $n_{\mathrm{in}}=100$ and $n_{\mathrm{out}}=50$, the variance is $2/150\approx0.01333$, and the standard deviation is $\sqrt{2/150}\approx0.11547$. The matching uniform distribution has $a=\sqrt{6/150}=0.2$: draw each weight between $-0.2$ and $0.2$.

He initialisation

For ReLU, $z=\max(0,a)$. Suppose the pre-activation distribution is symmetric about zero. The positive and negative halves contribute equally to $\mathbb E[a^2]$, but ReLU keeps only the positive half. Hence

$$\mathbb E[\operatorname{ReLU}(a)^2]=\tfrac12\mathbb E[a^2].$$

This is a statement about the second moment, not the variance of the ReLU output. Its mean is generally positive, and $\operatorname{Var}(z)=\mathbb E[z^2]-\mathbb E[z]^2$.

Suppose the $M$ incoming weights are independent, zero mean, have common variance $\sigma_w^2$, and are independent of the previous activations. Omit biases and assume similar activation statistics across units. Expanding the square, independence and zero weight means make the cross terms vanish:

$$\begin{aligned}\mathbb E[(a_i^{(l)})^2]&=\sum_{j=1}^M\mathbb E[(w_{ij}^{(l)})^2]\mathbb E[(z_j^{(l-1)})^2]\\&=M\sigma_w^2\mathbb E[(z_j^{(l-1)})^2].\end{aligned}$$

With symmetric pre-activations, applying ReLU gives

$$\mathbb E[(z_i^{(l)})^2]=\frac{M\sigma_w^2}{2}\mathbb E[(z_j^{(l-1)})^2].$$

Setting the factor to one approximately preserves the second moment, yielding

$$\boxed{\sigma_w^2=\frac{2}{M}=\frac{2}{n_{\mathrm{in}}}},\qquad \boxed{w_{ij}\sim\mathcal N\!\left(0,\frac{2}{n_{\mathrm{in}}}\right)},\qquad \sigma_w=\sqrt{\frac{2}{n_{\mathrm{in}}}}.$$

The factor two compensates for the half of the pre-activation second moment removed by ReLU. The Gaussian's second argument is the variance; sampling code that expects a standard deviation needs its square root. The result depends on the stated assumptions and describes an average over random weights, not a guarantee for each finite network or for training. Variants exist for other activations, including leaky ReLU.

Worked example

For $n_{\mathrm{in}}=256$, $\sigma_w^2=2/256=0.0078125$ and $\sigma_w=\sqrt{0.0078125}\approx0.08839$. A fixed standard deviation of $0.01$ does not adjust when the width changes; here its variance is $0.0001$, much smaller than the He value. Random differences address symmetry; choosing their scale addresses signal propagation. These are related but separate goals. Neither Xavier nor He guarantees successful optimisation: architecture, activation, depth, data and optimiser all matter. Biases are commonly initialised separately. Residual and other specialised architectures may use different rules. Pretrained parameters provide another starting point, as in the earlier discussion of transfer learning.

Why input feature scales matter

Initial parameters are only one part of the problem. In $y=w_1x_1+w_2x_2$, a given change to $w_2$ changes the prediction much more than the same change to $w_1$ when $|x_2|$ is much larger. This can produce very different curvatures in parameter space, connecting feature scales to the condition number and narrow valleys of the earlier convergence note.

Worked example

Take the four input pairs $(-1,-100)$, $(-1,100)$, $(1,-100)$ and $(1,100)$, with $t=2x_1+0.03x_2$. For $y=w_1x_1+w_2x_2$ and mean half-squared error,

$$E(\mathbf w)=\frac{1}{2N}\sum_{n=1}^N(y_n-t_n)^2,\qquad \mathbf H=\frac1N\mathbf X^\mathsf T\mathbf X.$$

Both feature means and their average product are zero. Their mean squares are $1$ and $10000$, so

$$E=\tfrac12\left[(w_1-2)^2+10000(w_2-0.03)^2\right],\quad \mathbf H=\begin{pmatrix}1&0\\0&10000\end{pmatrix},\quad \kappa=10000.$$

The $w_2$ direction is 10000 times as curved. For convergence from arbitrary initial parameters on this positive definite quadratic, $0<\eta<2/10000$. At such a rate, the error along $w_1$ is multiplied by $1-\eta$ each step, close to one. A rate near the upper limit can also cause oscillations in the steep direction. The small permitted rate makes progress along the shallow direction extremely slow.

Standardisation

For feature $i$, calculate the training mean and variance, then subtract the mean and divide by the standard deviation:

$$\mu_i=\frac1N\sum_n x_{ni},\quad \sigma_i^2=\frac1N\sum_n(x_{ni}-\mu_i)^2,\quad \boxed{\tilde x_{ni}=\frac{x_{ni}-\mu_i}{\sigma_i}},\quad \sigma_i>0.$$

Subtraction centres the values because $N^{-1}\sum_n(x_{ni}-\mu_i)=0$. Their new mean is zero and their variance is $N^{-1}\sum_n(x_{ni}-\mu_i)^2/\sigma_i^2=1$. A constant feature has $\sigma_i=0$ and cannot be divided by it; an implementation must handle it explicitly, for example by dropping it or using a safe scale.

In the example, $\mu_1=\mu_2=0$, $\sigma_1=1$ and $\sigma_2=100$. Thus $\tilde x_1=x_1$ and $\tilde x_2=x_2/100$. The same target is now $t=2\tilde x_1+3\tilde x_2$. The coefficient changes because its input coordinate changed, even though the predictions represent the same relationship. The standardised Hessian is $\tilde{\mathbf H}=\mathbf I$ and $\tilde\kappa=1$; its contours are circular in the new parameter coordinates. Gradient descent now converges from arbitrary starts for $0<\eta<2$.

This perfect conditioning is specific to this uncorrelated example. Standardisation makes marginal feature variances equal, but does not remove correlations. Correlated features can still produce a poorly conditioned Hessian, and nonlinear networks need not have this quadratic geometry.

Normalisation in practice

Fit preprocessing on the training data only, then apply the same stored transformation to validation, test and future inputs:

$$\tilde x_i=\frac{x_i-\mu_i^{\mathrm{train}}}{\sigma_i^{\mathrm{train}}}.$$

Calculating statistics from held-out examples leaks information into the training procedure in the usual supervised evaluation setting. Separately normalising each held-out set also puts it in a different representation from the one the model learned. In cross-validation, fit the transformation anew within each training fold and apply it to that fold's validation data.

Standardisation is natural for continuous numerical features, but binary indicators and categorical encodings need deliberate choices rather than automatic scaling. Means and standard deviations are sensitive to outliers; robust scaling based on medians and quantiles can be useful. Another choice is min–max normalisation:

$$\tilde x=\frac{x-x_{\min}}{x_{\max}-x_{\min}}.$$

With a nonzero training range this maps the observed training minimum and maximum to zero and one. It is not the same as zero-mean, unit-variance standardisation. Future values outside that range can map outside $[0,1]$; constant features again require special handling. If input distributions change over time, stored statistics may become less representative. Treat preprocessing as part of the complete prediction pipeline and monitor it alongside the model.

Adaptive optimisers can partially compensate for different gradient scales, but cannot eliminate every consequence of poorly scaled inputs or feature correlations. Optimiser choice changes the update rule; input normalisation changes the representation and hence the optimisation problem.

Summary

Initialisation chooses the starting point and influences symmetry, activations and gradients. Xavier balances forward and backward scaling considerations, while He accounts for ReLU's effect on the second moment. Feature standardisation can improve the geometry of optimisation, though neither technique guarantees successful training. Fit input transformations on training data and carry them into inference.
