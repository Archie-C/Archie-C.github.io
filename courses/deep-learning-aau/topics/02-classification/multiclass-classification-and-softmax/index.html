Multiclass Classification and Softmax.

So far, we have classified observations into two classes. Many problems have more possible outcomes, so now we need to extend our classifier.

What this note covers

  • Multiclass classification
  • One score per class
  • The softmax function
  • Multiclass cross-entropy
  • Implementation details

For a more formal definition, see Deep learning: Foundations and Concepts.

The multiclass problem

Suppose we want to classify flowers using two measurements. Each flower belongs to one of three classes: red, blue, or yellow. The points below show a simple example where the groups are easy to distinguish.

Binary logistic regression only needed to answer, “Is this class 1 or class 0?” Now we need to choose between several classes:

$$\mathcal{C}_1,\mathcal{C}_2,\ldots,\mathcal{C}_K.$$

Here $K$ is the number of classes. In our flower example, $K=3$.

One score per class

For binary classification, we calculated one linear score, $a(\mathbf{x})=\mathbf{w}^T\mathbf{x}+w_0$. For multiclass classification, we give each class its own score:

$$a_k(\mathbf{x})=\mathbf{w}_k^T\mathbf{x}+w_{k0},\qquad k=1,\ldots,K.$$

Each class gets its own weights and therefore its own score. With three classes, we have $a_1(\mathbf{x})$, $a_2(\mathbf{x})$, and $a_3(\mathbf{x})$. A larger score means the model considers that class more plausible.

For example, the scores might be

$$a_1=1.2,\qquad a_2=3.1,\qquad a_3=-0.4.$$

Class 2 has the largest score, but these are unrestricted real numbers, not probabilities. We need to turn them into values between 0 and 1 that add up to one.

The softmax function

For each class, softmax exponentiates its score and divides by the sum of all the exponentials:

$$y_k=\frac{\exp(a_k)}{\sum_{j=1}^{K}\exp(a_j)}.$$

The exponential makes each value positive. Dividing by their sum normalises the values, so $0<y_k<1$ and $\sum_{k=1}^{K}y_k=1$. We can then read each output as a class probability:

$$y_k=p(\mathcal{C}_k\mid\mathbf{x}).$$

important

Softmax takes the set of class scores and turns them into a probability distribution over the classes.

A small softmax example

Let's use the scores from above. Their exponentials are approximately $3.320$, $22.198$, and $0.670$. Their sum is about $26.188$, so the probabilities are

$$\begin{aligned}y_1&=3.320/26.188\approx0.127,\\y_2&=22.198/26.188\approx0.848,\\y_3&=0.670/26.188\approx0.026.\end{aligned}$$

As expected, class 2 has the largest probability. To make a prediction, we choose the class with the largest probability:

$$\hat{k}=\arg\max_k y_k.$$

In plain English, this means “choose the index of the largest probability.” Softmax preserves the ordering of scores, so it is also the class with the largest score: $\hat{k}=\arg\max_k a_k$.

Why not apply sigmoid to every class?

If we applied sigmoid independently to three scores, we might get probabilities such as $0.8$, $0.7$, and $0.6$. These values do not have to sum to one.

When an observation belongs to exactly one class, the classes compete: increasing the probability of one class leaves less probability for the others. Softmax captures this by making the probabilities sum to one. Independent sigmoids are useful when several labels can be true at the same time, which is a different problem.

Decision boundaries

The model predicts whichever class has the largest score. The boundary between classes $i$ and $j$ is where their scores are equal:

$$a_i(\mathbf{x})=a_j(\mathbf{x}).$$

Substituting the linear scores and rearranging gives

$$ (\mathbf{w}_i-\mathbf{w}_j)^T\mathbf{x}+(w_{i0}-w_{j0})=0. $$

This is still a linear boundary. A multiclass linear classifier divides the input space into regions, with one predicted class in each region.

Representing the target

During training, we know which class each observation belongs to. For a flower in class 2, we can represent the target as

$$\mathbf{t}=\begin{pmatrix}0\\1\\0\end{pmatrix}.$$

Exactly one element is 1 because exactly one class is correct. For $K$ classes, we can write each target value as

$$t_k=\begin{cases}1 & \text{if the observation belongs to class }k,\\0 & \text{otherwise.}\end{cases}$$

This representation is commonly called one-hot encoding.

Multiclass cross-entropy

We already used binary cross-entropy to reward a model for assigning high probability to the class that occurred. The same idea extends naturally to $K$ classes. For one observation, the loss is

$$\mathcal{L}=-\sum_{k=1}^{K}t_k\log y_k.$$

Only one target value is 1, so all the other terms disappear. If class 2 is correct, for example, then $\mathcal{L}=-\log y_2$. The loss is the negative log probability assigned to the correct class.

For a dataset of $N$ observations, we add the loss for each observation, or take its mean:

$$\mathcal{L}=-\sum_{n=1}^{N}\sum_{k=1}^{K}t_{nk}\log y_{nk},\qquad \mathcal{L}_{\mathrm{mean}}=-\frac{1}{N}\sum_{n=1}^{N}\sum_{k=1}^{K}t_{nk}\log y_{nk}.$$

This is the multiclass version of the cross-entropy loss derived in the previous note.

important

Because the target is one-hot encoded, multiclass cross-entropy is simply the negative log probability assigned to the correct class.

A quick loss example

Suppose the true class is class 2. Three models assign it probabilities of $0.90$, $0.40$, and $0.10$. Their losses are

$$-\log(0.90)\approx0.105,\qquad-\log(0.40)\approx0.916,\qquad-\log(0.10)\approx2.303.$$

Model A gets a small loss, and Model B gets a larger one. Model C is confidently wrong and receives a much larger loss.

Numerical stability

Softmax contains exponentials, which can become very large for large scores. In practice, we subtract the largest score before exponentiating:

$$y_k=\frac{\exp(a_k-\max_j a_j)}{\sum_j\exp(a_j-\max_j a_j)}.$$

Subtracting the same value from every score does not change the probabilities. It simply keeps the exponentials smaller and easier to calculate.

Implementation

We can implement softmax with NumPy. Each row of scores contains the scores for one observation. We subtract the largest score in each row, exponentiate, then divide each value by its row's sum.

import numpy as np

def softmax(scores):
    shifted_scores = scores - np.max(
        scores, axis=1, keepdims=True
    )
    exp_scores = np.exp(shifted_scores)
    return exp_scores / np.sum(
        exp_scores, axis=1, keepdims=True
    )

The keepdims=True argument keeps the row dimension so NumPy can divide each score by the sum for its observation.

Setting up the classifier

With $D$ input features and $K$ classes, we use a weight matrix $W\in\mathbb{R}^{D\times K}$ and a bias vector $\mathbf{b}\in\mathbb{R}^{K}$. For a matrix of inputs $X$, the score matrix is $A=XW+\mathbf{b}$, and the probabilities are $Y=\operatorname{softmax}(A)$.

Here is the start of a classifier. We initialise the weights once we know how many input features and classes there are. In the code below, class labels are integer indices starting at 0.

class SoftmaxClassifier:
    def __init__(self, learning_rate=0.1, epochs=1000):
        self.learning_rate = learning_rate
        self.epochs = epochs
        self.weights = None
        self.bias = None
        self.loss_history = []

    @staticmethod
    def _softmax(scores):
        shifted = scores - np.max(
            scores, axis=1, keepdims=True
        )
        exp_scores = np.exp(shifted)
        return exp_scores / np.sum(
            exp_scores, axis=1, keepdims=True
        )

The matrix product gives one score per class. Softmax then converts each row of scores into a row of probabilities:

    def decision_function(self, X):
        return X @ self.weights + self.bias

    def predict_proba(self, X):
        return self._softmax(
            self.decision_function(X)
        )

    def predict(self, X):
        probabilities = self.predict_proba(X)
        return np.argmax(probabilities, axis=1)

np.argmax returns the index of the largest value in each row, giving the predicted class.

Computing multiclass cross-entropy

We can keep the labels as integer class indices. This function looks up the probability assigned to the correct class in each row, clips it away from zero, and averages the negative log probabilities.

def cross_entropy(y_true, y_pred):
    eps = 1e-12
    y_pred = np.clip(y_pred, eps, 1.0)
    correct = y_pred[np.arange(len(y_true)), y_true]
    return -np.mean(np.log(correct))

For example, if y_true[0] is 2, then y_pred[0, 2] is the probability assigned to the correct class for the first observation.

Training the model

The gradient keeps the same familiar prediction-minus-target form as in logistic regression. Here both values are vectors, one entry per class. We convert the integer labels to one-hot rows so that we can subtract them from the predicted probabilities.

For the mean loss, the parameter gradients are $\nabla_W\mathcal{L}=X^T(Y-T)/N$ and $\nabla_{\mathbf{b}}\mathcal{L}=\operatorname{mean}(Y-T)$. We can therefore adapt the same gradient-descent update:

    def fit(self, X, y):
        n_samples, n_features = X.shape
        y = np.asarray(y, dtype=int)
        n_classes = int(np.max(y)) + 1
        targets = np.eye(n_classes)[y]

        self.weights = np.zeros(
            (n_features, n_classes)
        )
        self.bias = np.zeros(n_classes)
        self.loss_history = []

        for _ in range(self.epochs):
            probabilities = self.predict_proba(X)
            self.loss_history.append(
                cross_entropy(y, probabilities)
            )
            error = probabilities - targets
            dw = X.T @ error / n_samples
            db = np.mean(error, axis=0)
            self.weights -= self.learning_rate * dw
            self.bias -= self.learning_rate * db

The rows of targets are one-hot encoded. Subtracting them from the probabilities gives the error for each class, and the updates move the weights and biases in the direction that reduces the mean cross-entropy.

Applying this to the flower example

Suppose our model gives one flower the scores $(0.8,\ 2.4,\ -0.3)$. Applying softmax gives approximately $(0.159,\ 0.788,\ 0.053)$.

So the prediction is $\hat{k}=2$. The model chooses class 2 because it receives the largest probability. We now have a way to turn measurements into class probabilities and a prediction.
