Maximum Likelihood and Binary Cross-Entropy.

Logistic regression gives us probabilities. Now we need a way to choose weights that make those probabilities agree with the observed labels.

What this note covers

  • Modelling binary targets probabilistically
  • The likelihood function
  • Maximum likelihood
  • Binary cross-entropy
  • Optimising logistic regression

For a more formal definition, see Deep learning: Foundations and Concepts.

Starting from logistic regression

In the previous note, we used logistic regression to turn a linear score into a probability:

$$y(\mathbf{x})=\sigma(\mathbf{w}^T\mathbf{x}+w_0),$$

where $y(\mathbf{x})=p(t=1\mid\mathbf{x})$. The target for each example is binary, so $t\in\{0,1\}$. Until now, we have treated the weights as if they were already known. We now need an objective that tells us whether a particular choice of weights explains the labels well.

The probability of one observation

For observation $n$, let $y_n=p(t_n=1\mid\mathbf{x}_n)$. The probability of target 1 is $y_n$, and the probability of target 0 is $1-y_n$.

We can write both cases in one expression:

$$p(t_n\mid\mathbf{x}_n,\mathbf{w})=y_n^{t_n}(1-y_n)^{1-t_n}.$$

For $t_n=1$, this becomes

$$y_n^1(1-y_n)^0=y_n,$$

and for $t_n=0$, it becomes

$$y_n^0(1-y_n)^1=1-y_n.$$

important

This compact expression just selects the probability assigned to the target that actually occurred.

This is a Bernoulli model: there are two possible outcomes, 0 and 1, with probabilities $1-y_n$ and $y_n$.

The likelihood of the dataset

Suppose our dataset is

$$\mathcal{D}=\{(\mathbf{x}_n,t_n)\}_{n=1}^{N}.$$

If the observations are independent given the model parameters, their probabilities multiply. The likelihood of all the observed targets is therefore

$$p(\mathbf{t}\mid\mathbf{X},\mathbf{w})=\prod_{n=1}^{N}y_n^{t_n}(1-y_n)^{1-t_n}.$$

Each observation contributes the probability the model assigned to the class that occurred. Multiplying these probabilities gives a measure of how plausible the whole dataset is under the model.

For example, take true labels $[1,0,1]$ and predicted probabilities for class 1 of $[0.9,0.2,0.7]$. The likelihood is

$$0.9\times(1-0.2)\times0.7=0.504.$$

A second model gives probabilities $[0.6,0.7,0.4]$. Its likelihood is $0.6\times(1-0.7)\times0.4=0.072$, which is much lower.

Why use the log-likelihood?

When many probabilities between 0 and 1 are multiplied, the result can become extremely small. Products are also awkward to work with, so we take the logarithm. Using $\log(ab)=\log a+\log b$ turns the product into a sum:

$$\begin{aligned}\log p(\mathbf{t}\mid\mathbf{X},\mathbf{w})&=\log\prod_{n=1}^{N} y_n^{t_n}(1-y_n)^{1-t_n}\\&=\sum_{n=1}^{N}\left[t_n\log y_n+(1-t_n)\log(1-y_n)\right].\end{aligned}$$

The log-likelihood is easier to calculate and optimise, and it ranks models in the same order as the likelihood.

important

The logarithm is strictly increasing, so the parameters that maximise the likelihood also maximise the log-likelihood.

From maximum likelihood to a loss

Maximum likelihood asks us to maximise the log-likelihood. Optimisation is often written as minimisation, so we instead minimise its negative:

$$\mathcal{L}=-\sum_{n=1}^{N}\left[t_n\log y_n+(1-t_n)\log(1-y_n)\right].$$

This is the binary cross-entropy loss. It is also common to use the mean over the examples:

$$\mathcal{L}_{\mathrm{BCE}}=-\frac{1}{N}\sum_{n=1}^{N}\left[t_n\log y_n+(1-t_n)\log(1-y_n)\right].$$

The sum and mean have the same minimiser. The mean just makes loss values easier to compare across datasets of different sizes.

important

Binary cross-entropy is not an arbitrary loss function. For logistic regression, it follows directly from maximum likelihood under a Bernoulli model for the targets.

The loss for one observation

For a positive example, where $t=1$, the loss reduces to $-\log y$. For a negative example, where $t=0$, it is $-\log(1-y)$.

A correct, confident prediction gives a small loss. An uncertain prediction gives a moderate loss. A confidently wrong prediction gives a very large loss.

Why not squared error?

In regression, squared error follows naturally when we model the targets with a Gaussian distribution. Here the targets are binary, so a Bernoulli distribution is a better fit. For logistic regression, maximum likelihood under that Bernoulli model gives us cross-entropy.

We could use squared error for a binary task, but it is not the natural probabilistic objective for the model we have defined.

The loss as a function of the score

Recall that $y=\sigma(a)$. For a positive example the loss is $-\log\sigma(a)$; for a negative example it is $-\log(1-\sigma(a))$.

Large positive scores are good for class 1, while large negative scores are good for class 0. A score far in the wrong direction gives a large loss.

Optimising logistic regression

Unlike ordinary least squares, logistic regression does not have the same simple closed-form solution. We usually find its weights iteratively: initialise them, compute predictions and the loss, calculate gradients, update the parameters, and repeat.

For one example, write the loss in terms of the score $a$:

$$\ell=-t\log y-(1-t)\log(1-y),\qquad y=\sigma(a).$$

The sigmoid derivative is $\frac{dy}{da}=y(1-y)$. Applying the chain rule gives

$$\frac{d\ell}{da}=\left(-\frac{t}{y}+\frac{1-t}{1-y}\right)y(1-y)=y-t.$$

Since $a=\mathbf{w}^T\mathbf{x}+w_0$, the score changes by $\mathbf{x}$ when we change the weights, and by 1 when we change the bias. So for the summed loss:

$$\frac{\partial\mathcal{L}}{\partial\mathbf{w}}=\sum_{n=1}^{N}(y_n-t_n)\mathbf{x}_n,\qquad\frac{\partial\mathcal{L}}{\partial w_0}=\sum_{n=1}^{N}(y_n-t_n).$$

For the mean BCE, divide both gradients by $N$. Each example contributes its prediction error, $y_n-t_n$, multiplied by its input. This prediction error times input pattern will appear again in neural networks.

Gradient descent turns these gradients into actual parameter updates. With learning rate $\eta$, subtract the gradient from each parameter:

$$\mathbf{w}\leftarrow\mathbf{w}-\eta\frac{1}{N}\sum_{n=1}^{N}(y_n-t_n)\mathbf{x}_n,\qquad w_0\leftarrow w_0-\eta\frac{1}{N}\sum_{n=1}^{N}(y_n-t_n).$$

The gradient points in the direction that increases the loss, so subtracting it moves the parameters downhill. The learning rate $\eta$ controls the size of each step: if it is too large, we can jump past a good solution; if it is small, learning takes longer. In the code below, dw and db are the two gradients, and the last two lines apply exactly these updates.

We repeat the following steps:

  1. Initialise the weights and bias.
  2. Compute the predicted probabilities.
  3. Compute the BCE and its gradients.
  4. Update the weights and bias.
  5. Repeat for a number of epochs.

Implementation

We can now extend the LogisticRegression class from the previous note. We will use NumPy to compute the mean BCE and its gradients.

Initialising the model

Start with a learning rate and number of epochs. The weights are initialised when we call fit, once we know how many input features there are.

import numpy as np

class LogisticRegression(Classifier):

    def __init__(self, learning_rate=0.01, epochs=1000):
        self.learning_rate = learning_rate
        self.epochs = epochs
        self.weights = None
        self.bias = 0.0
        self.loss_history = []

Computing the loss

We clip probabilities slightly away from 0 and 1 because $\log(0)$ is undefined. This function calculates the mean loss across the examples:

def binary_cross_entropy(y_true, y_pred):
    eps = 1e-12
    y_pred = np.clip(y_pred, eps, 1 - eps)
    return -np.mean(
        y_true * np.log(y_pred)
        + (1 - y_true) * np.log(1 - y_pred)
    )

Computing predictions and gradients

Add these methods to the class. The sigmoid and decision function give us probabilities. In each training step, the difference between the predicted probability and target gives the error used for both gradients.

    def _sigmoid(self, scores):
        scores = np.clip(scores, -500, 500)
        return 1 / (1 + np.exp(-scores))

    def decision_function(self, X):
        return X @ self.weights + self.bias

    def predict_proba(self, X):
        return self._sigmoid(self.decision_function(X))

Updating the parameters

The matrix product X.T @ error adds each input weighted by its prediction error. Dividing by the number of examples gives the gradients for the mean BCE. We then take a small step in the opposite direction.

    def fit(self, X, y):
        n_samples, n_features = X.shape
        y = np.asarray(y)
        self.weights = np.zeros(n_features)
        self.bias = 0.0
        self.loss_history = []

        for _ in range(self.epochs):
            probabilities = self.predict_proba(X)
            self.loss_history.append(
                binary_cross_entropy(y, probabilities)
            )
            error = probabilities - y
            dw = X.T @ error / n_samples
            db = np.mean(error)
            self.weights -= self.learning_rate * dw
            self.bias -= self.learning_rate * db

Making predictions

As before, we use a threshold of 0.5 to turn probabilities into class labels:

    def predict(self, X):
        probabilities = self.predict_proba(X)
        return (probabilities >= 0.5).astype(int)

These methods are the pieces of the LogisticRegression class. The abstract Classifier base class is the one introduced in 2.1.
