Logistic Regression.

A linear score tells us which side of a boundary an input lies on. Logistic regression turns that score into a probability.

What this note covers

  • The logistic sigmoid
  • From scores to probabilities
  • Logistic regression
  • Making predictions
  • Implementation details

For a more formal definition, see Deep learning: Foundations and Concepts.

From a score to a probability

In the previous note, we used the linear decision function

$$a(\mathbf{x}) = \mathbf{w}^T\mathbf{x} + w_0.$$

It can return any real number:

$$-\infty < a(\mathbf{x}) < \infty.$$

We only used its sign: a positive score meant class 1, and a negative score meant class 0. But a score such as $3.7$ or $-1.4$ is not itself a probability. For binary classification, we would like the model to give us $p(t=1\mid\mathbf{x})$, a value between 0 and 1.

The logistic sigmoid

The logistic sigmoid takes any real-valued score and maps it into that interval:

$$\sigma(a) = \frac{1}{1 + e^{-a}}.$$

Very negative scores are mapped close to 0. A score of 0 maps to 0.5, and very positive scores are mapped close to 1.

important

The sigmoid does not change the ordering of scores. A larger linear score still gives a larger output.

From scores to probabilities

We can combine the linear decision function with the sigmoid. Let

$$a(\mathbf{x}) = \mathbf{w}^T\mathbf{x} + w_0$$

and define

$$y(\mathbf{x}) = \sigma(a(\mathbf{x}))$$

or, written out,

$$y(\mathbf{x}) = \frac{1}{1+\exp\left(- (\mathbf{w}^T\mathbf{x}+w_0)\right)}.$$

We interpret this output as the probability of class 1:

$$y(\mathbf{x}) = p(t=1\mid\mathbf{x}).$$

For the other class,

$$p(t=0\mid\mathbf{x}) = 1-y(\mathbf{x}).$$

This model is called logistic regression.

note

Logistic regression is used for classification. The name comes from constructing a continuous linear score and transforming it with the logistic function.

Interpreting the output

Suppose a particular input has score $a(\mathbf{x})=1.5$. Its predicted probability of class 1 is

$$\sigma(1.5)=\frac{1}{1+e^{-1.5}}\approx 0.82.$$

So we read this as $p(t=1\mid\mathbf{x})\approx 0.82$.

With a negative score, say $a(\mathbf{x})=-1.5$, the output is about $0.18$. The sigmoid is symmetric around 0.5:

$$\sigma(-a)=1-\sigma(a).$$

Making predictions

To turn the probability into a class prediction, we use a threshold of 0.5:

$$\hat{t}=\begin{cases}1 & y(\mathbf{x}) \geq 0.5 \\ 0 & y(\mathbf{x}) < 0.5.\end{cases}$$

Since $\sigma(0)=0.5$, the output is 0.5 exactly when

$$\mathbf{w}^T\mathbf{x}+w_0=0.$$

That is the same linear decision boundary we introduced in the previous note.

important

Applying the sigmoid changes how we interpret the model output, but it does not change the location of the 0.5 decision boundary.

Applying this to our admissions example

Let us return to the fictional admissions data. We will use a fixed model for now; how to learn its weights comes later. Choose

$$a(\mathbf{x})=0.12x_1+0.08x_2-11.2.$$

The boundary is still the same line from the previous note, just with all terms scaled by one tenth. A student on the line has predicted probability 0.5; students on either side get probabilities below or above 0.5.

How the score affects the probability

Points in the positive direction of the weight vector get larger linear scores and therefore larger probabilities. The chain is

$$\mathbf{x} \rightarrow a(\mathbf{x}) \rightarrow \sigma(a) \rightarrow p(t=1\mid\mathbf{x}).$$

The score is what matters here; probability is not simply Euclidean distance from the boundary.

note

Multiplying all weights and the bias by the same positive constant leaves the boundary in the same place, but changes how quickly probabilities move towards 0 and 1.

Implementation

We can extend the Classifier abstraction from the previous note. The weights and bias are supplied here, so this example focuses on prediction rather than learning them.

First, decision_function computes the linear score for each input. Then predict_proba applies the sigmoid to turn each score into a probability.

import numpy as np

class LogisticRegression(Classifier):

    def __init__(self, weights, bias):
        self.weights = np.asarray(weights)
        self.bias = bias

    def fit(self, X, y):
        raise NotImplementedError("Learning the weights comes next.")

    def decision_function(self, X):
        return X @ self.weights + self.bias

    def predict_proba(self, X):
        scores = self.decision_function(X)
        scores = np.clip(scores, -500, 500)
        return 1 / (1 + np.exp(-scores))

    def predict(self, X):
        probabilities = self.predict_proba(X)
        return (probabilities >= 0.5).astype(int)

Finally, predict uses a threshold of 0.5 to turn those probabilities into class labels. The small fit placeholder is needed because Classifier declares it as an abstract method; we will implement learning in the next note.

note

For very large negative scores, directly evaluating np.exp(-scores) can overflow. Clipping the scores before exponentiation is a compact safeguard for this introductory implementation.
