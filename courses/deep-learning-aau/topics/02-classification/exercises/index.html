  1. 01

    Question 1

    A binary classifier predicts class A when

    $$ a(\mathbf{x}) = w_0 + w_1 x_1 + w_2 x_2 > 0 $$

    with

    $$ w_0 = -1, w_1 = 2, w_2 = -3 $$

    1. Predict the class for the input vectors $\mathbf{x} = (1, 1)$ and $\mathbf{x} = (0, 1)$.
    2. Derive the decision boundary for this classifier.
    3. Explain geometrically what $w_0$, and the vector $\mathbf{w} = (w_1, w_2)$ control.
    4. Explain what happens to the decision boundary if only $w_0$ is increased.
  2. 02

    Question 2

    A classifier is used to detect a rare manufacturing defect. On 1000 components:

    • 20 are actually defective.
    • The model correctly detects 12.
    • The model incorrectly flags 30 non-defective components.
    1. Construct a confusion matrix for this data.
    2. Calculate the accuracy, precision and recall of the classifier.
    3. A classifier that predicts "non-defective" for all components obtains what accuracy for this example?
    4. Explain why accuracy is a poor evaluation metric for this problem.
    5. Which metric would you prioritise if allowing a defective component through is particularly dangerous?
  3. 03

    Question 3

    Consider a binary training set that is perfectly linearly separable and a logistic regression model trained by maximum-likelihood.

    1. Suppose $\mathbf{w}$ correctly separates all observations. Explain what happens to the predicted probabilities if we replace $\mathbf{w}$ with $c\mathbf{w}$ for some $c > 1$.
    2. What happens to the cross-entropy training loss as $c \to \infty$?
    3. Explain why the unregularised maximum-likelihood estimate therefore does not have a finite optimum in this case.
    4. In the context of the question, does this mean that logistic regression cannot correctly classify all observations?
    5. Explain how $L_2$ regularisation addresses this issue when the training set is perfectly linearly separable.
    6. Does applying $L_2$ regularisation necessarily preserve the original decision boundary? Explain your reasoning.
