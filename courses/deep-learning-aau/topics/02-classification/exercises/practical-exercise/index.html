Practical exercise 2026: Rocket Control

Train a classifier to guide a rocket to a safe landing.

Task

practical exercise

Implement a multi-class classification from scratch using only NumPy.

In the data there are 10 classes (0-9) representing the actions the rocket can take, and 12 observations you can use as input variables. The data is generated from a simulation of 1000 landings using an Model Predictive Control (MPC) "expert" controller. This is not a perfect controller so some landings are unsuccessful.

Your class must be named Controller and must implement a fit(X, y) method, a predict(X) method and a predict_action(observation) method.

The model will be scored in 4 dimensions: landing success, landing score, action F1 and action accuracy. I do not provide the simulator code but you can upload your controller to this page to inspect the simulations on 10 validation initial conditions. Again the test set is private and the leaderboard is based on the test set, not the validation set.

Download the training data, starter controller and training notebook. Once you are happy with your controller, you can upload it here to run the validation flights and submit to the leaderboard.

For those of you who are looking for a good score you may find the physics behind the simulation, informative for basis functions.

IMPORTANT: The moodle pdf outlines the exact submission requirements.

Run a controller

Initially, everything runs in your browser. Note that training may take a while and use substantial memory. To avoid that you can upload a pre-trained model weights file to skip training.

Controller and dataset guide

Each row of the training CSV contains observations and an action at that timestep. There are 12 basic features, use action as the label y.

ColumnMeaningUnits
xHorizontal position relative to the pad centrem
yCentre-of-mass height relative to the padm
vx, vyHorizontal and vertical velocity; upward is positivem/s
theta, omegaTilt and angular velocity; anticlockwise is positiverad, rad/s
fuel_massRemaining fuelkg
actual_thrust, actual_gimbalCurrent engine thrust and gimbal angleN, rad
wind_x, wind_yHorizontal and vertical wind velocitym/s
air_densityAir density at the rocketkg/m³

Additionally, run_id and step identify the landing number and the order of decisions. The success column indicates the final outcome of each landing, not a feature to be used in training. The success is the eventual flight outcome, not an input: using it as a feature would leak information unavailable to the controller in flight.

The simulator calls predict_action(observation) every 0.1 seconds. Return a single integer from 0 to 9. Action 0 turns the engine off. Actions 1–3 use low thrust, 4–6 medium thrust, and 7–9 high thrust; within each group the gimbal is left, centred, then right.

After training, the page runs separate validation and test flights in your browser. When you submit, predicted actions are sent to the cloud for comparison with private expert labels. The leaderboard uses the test flights. Action agreement and landing success measure different things. Test observations are public; the expert test labels are stored separately.
