Linear Classifiers and Decision Boundaries.

How do we go from regression to classification?

What this note covers

  • The classification problem
  • Linear decision functions
  • Decision boundaries
  • Linear separability
  • Implementation details

For a more formal definition, see Deep learning: Foundations and Concepts.

The classification problem

Below we have some data from a fictional admissions problem. For each student, we have measured their entrance exam score and interview score, along with whether or not they were admitted.

Looking at the data, we can see that the admitted and rejected students occupy different regions of the input space.

Instead of drawing a line of best fit through the points, as we did in regression, we now want to draw a line that separates the two classes as well as possible.

The question is: how do we define such a line mathematically?

Defining the boundary

You should already be familiar with the equation of a line:

$$ y = mx + c $$

For classification, however, we are not interested in predicting the value of $y$ directly. Instead, we want to use a line to divide the input space into two regions.

Suppose our input has two features, $x_1$ and $x_2$. We can define a linear function:

$$ a(\mathbf{x}) = w_1x_1 + w_2x_2 + w_0. $$

where $w_1$ and $w_2$ control the orientation of the line and $w_0$ controls its position.

The decision boundary occurs wherever $a(\mathbf{x}) = 0$. Therefore:

$$ w_1x_1 + w_2x_2 + w_0 = 0 $$

Making a prediction

Once we have a defined a decision boundary, classification becomes quite simple.

If

$$ a(\mathbf{x}) > 0, $$

we assign the input to one class, and if

$$ a(\mathbf{x}) < 0, $$

we assign it to the other class.

For example,

$$ \hat{t} = \begin{cases} 1 & \text{if } a(\mathbf{x}) \geq 0, \\ 0 & \text{if } a(\mathbf{x}) < 0. \end{cases} $$

The decision boundary itself corresponds to

$$ a(\mathbf{x}) = 0. $$

important

The function $a(\mathbf{x})$ does not yet give us a probability. It simply gives us a score. The sign of this score tells us which side of the decision boundary a point lies on.

Understanding the geometry

Consider the boundary

$$1.2x_1 + 0.8x_2 - 112 = 0.$$

Rearranging gives,

$$x_2 = -1.5x_1 + 140.$$

So this is simply a straight line.

The weight vector is

$$\mathbf{w} = \begin{bmatrix} 1.2 \\ 0.8 \end{bmatrix}.$$

An important geometric property is that the weight vector is perpendicular to the decision boundary. This means that changing $\mathbf{w}$ will rotate the decision boundary, while changing $w_0$ will shift it along its normal direction.

Applying this to our admissions example

Suppose we choose

$$ \mathbf{w} = \begin{pmatrix} 1.2 \\ 0.8 \end{pmatrix}, \qquad w_0 = -112. $$

The decision function is therefore

$$ a(\mathbf{x}) = 1.2x_1 + 0.8x_2 - 112. $$

Any student with

$$a(\mathbf{x}) \geq 0$$

is classified as admitted, while students with

$$a(\mathbf{x}) < 0$$

are classified as rejected.

Higher-dimensional inputs

So far we have considered two input features because they are easy to visualise.

If the input has $D$ features, then we write

$$ a(\mathbf{x}) = \mathbf{w}^T\mathbf{x} + w_0. $$

The decision boundary is then

$$ \mathbf{w}^T\mathbf{x} + w_0 = 0. $$

With two input dimensions, this boundary is a line.

With three input dimensions, it is a plane.

In higher dimensions, it is called a hyperplane.

Linear separability

A dataset is called linearly separable if there exists a straight line that perfectly separates the classes.

In this case, we can choose values of the weights such that every observation lies on the correct side of the boundary.

However, not every dataset is linearly separable.

For example, if one class forms a region surrounded by another class, no single straight line can separate them perfectly.

This is one of the main limitations of a basic linear classifier.

Implementation

We can implement a simple linear classifier directly.

First, let us define a small base class:

from abc import ABC, abstractmethod

class Classifier(ABC):

    @abstractmethod
    def fit(self, X, y):
        raise NotImplementedError

    @abstractmethod
    def predict(self, X):
        raise NotImplementedError

Then we can implement a linear classifier as follows:

import numpy as np

class LinearClassifier(Classifier):

    def __init__(self, weights, bias):
        self.weights = np.asarray(weights)
        self.bias = bias

    def decision_function(self, X):
        return X @ self.weights + self.bias

    def predict(self, X):
        scores = self.decision_function(X)
        return (scores >= 0).astype(int)
Note

We don't implement the fit method in this simple example, that will come up in the next section when we look at logistic regression.

Next Steps

So far, we have assumed that the values of the weights are already known.

The next question is how we should choose these weights from data.

We could try to fit them directly, but unlike regression, the output we ultimately want is a class probability rather than an unrestricted real number.
