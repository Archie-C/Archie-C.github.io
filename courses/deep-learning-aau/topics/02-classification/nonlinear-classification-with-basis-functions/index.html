Nonlinear Classification with Basis Functions.

A straight-line boundary cannot separate every dataset. Transforming the inputs first lets the same classifier draw more flexible boundaries.

What this note covers

  • The limitation of linear decision boundaries
  • Basis-function transformations
  • Classification in feature space
  • Polynomial decision boundaries
  • Implementation details

For a more formal definition, see Deep learning: Foundations and Concepts.

The limitation of a linear classifier

In the previous notes, we used logistic regression to turn a linear score into a probability:

$$y(\mathbf{x})=\sigma(\mathbf{w}^T\mathbf{x}+w_0).$$

The predicted probability is useful, but the score still has a limitation. Its 0.5 boundary occurs when

$$\mathbf{w}^T\mathbf{x}+w_0=0.$$

If $\mathbf{x}$ contains the original input variables, this equation is linear in those variables. With two inputs, it describes a straight line.

Now consider a simple dataset with one class near the centre and another spread around it. No matter where we draw a straight line, it cannot put all of the central points on one side and all of the surrounding points on the other. The issue is not that logistic regression cannot give useful probabilities. Its linear score is too restrictive for this pattern.

Transforming the input

In nonlinear regression, we transformed the inputs with basis functions before fitting a linear model. We can use the same idea here. Instead of applying logistic regression directly to $\mathbf{x}$, first map it to a feature vector:

$$\mathbf{x}\longrightarrow\boldsymbol{\phi}(\mathbf{x}).$$

The score is now a weighted sum of the transformed features, plus a bias:

$$a(\mathbf{x})=\mathbf{w}^T\boldsymbol{\phi}(\mathbf{x})+w_0.$$

We then pass that score through the same sigmoid as before:

$$y(\mathbf{x})=\sigma\left(\mathbf{w}^T\boldsymbol{\phi}(\mathbf{x})+w_0\right)=p(t=1\mid\mathbf{x}).$$

The 0.5 boundary is still where the score is zero, so $\mathbf{w}^T\boldsymbol{\phi}(\mathbf{x})+w_0=0$.

important

The classifier is still linear in the transformed features $\boldsymbol{\phi}(\mathbf{x})$, but its decision boundary does not need to be linear in the original input $\mathbf{x}$.

A simple nonlinear transformation

Return to the centre-and-surrounding-points example. A useful feature is

$$\phi(\mathbf{x})=x_1^2+x_2^2.$$

This is the squared distance from the origin. Points near the centre have small values; points farther away have larger values. So the two classes that overlap when we look at $(x_1,x_2)$ separately can become easy to distinguish using this one feature.

For example, use the score

$$a(\mathbf{x})=w_1(x_1^2+x_2^2)+w_0.$$

The decision boundary occurs when the score is zero:

$$w_1(x_1^2+x_2^2)+w_0=0.$$

If $w_1\ne 0$, rearranging gives

$$x_1^2+x_2^2=-\frac{w_0}{w_1}.$$

This is the equation of a circle centred at the origin. The model itself has not become a complicated nonlinear algorithm. We have changed the features supplied to the same logistic classifier.

Feature space

The space made by the transformed features is called feature space. For the feature $z=x_1^2+x_2^2$, each original observation $(x_1,x_2)$ is represented by a single number, $z$.

In this new space, the centre points have small $z$ values and the surrounding points have large ones. A threshold $c$ can separate them: one class has $z<c$, while the other has $z>c$. The curved separation in the original view has become a simple linear threshold in feature space.

Polynomial basis functions

We chose the radial feature because it suited this particular dataset. A more general choice is to include polynomial terms for both inputs. One degree-2 basis is

$$\boldsymbol{\phi}(\mathbf{x})=\begin{pmatrix}1\\x_1\\x_2\\x_1^2\\x_1x_2\\x_2^2\end{pmatrix}.$$

The score becomes

$$a(\mathbf{x})=\mathbf{w}^T\boldsymbol{\phi}(\mathbf{x})=w_0+w_1x_1+w_2x_2+w_3x_1^2+w_4x_1x_2+w_5x_2^2.$$

The boundary is still found by setting $a(\mathbf{x})=0$, but it can now be curved. Depending on the weights, it can describe circles, ellipses, parabolas, and other quadratic curves. The main point is the added flexibility; we do not need to study each curve in detail.

Linear in the parameters

Compare $w_0+w_1x$ with $w_0+w_1x+w_2x^2$. The second score is nonlinear in the input $x$, because it contains $x^2$. But both expressions are linear in their parameters: each weight appears only as a coefficient, not inside a nonlinear function.

This is the same distinction we made for nonlinear regression. We can use the word “linear” for the relationship to the parameters even when the curve in the original input space is not a straight line.

important

A linear model does not necessarily produce a straight line in the original input space. It is called linear because the parameters enter the model linearly.

Other basis functions

Polynomial functions are not the only option. In nonlinear regression, we also saw Gaussian or radial basis functions, for example

$$\phi_j(\mathbf{x})=\exp\left(-\frac{\|\mathbf{x}-\boldsymbol{\mu}_j\|^2}{2s^2}\right),$$

and sigmoidal basis functions. The same basis-functions can be reused for classification. The difference is in the output: regression maps a linear combination of basis features to a continuous prediction, while binary classification applies a sigmoid to that score to produce a class probability.

As with polynomial regression, adding more basis functions gives the classifier more ways to fit the data. A degree-1 polynomial gives a linear boundary; degree 2 allows quadratic boundaries. Richer transformations can draw more complicated boundaries, but they can also fit noise and overfit the training examples.

Implementation

The logistic-regression algorithm does not need to change. We transform the inputs first, then reuse the same fit and predict methods from the previous note.

Here is a manual degree-2 feature transformation using NumPy:

def polynomial_features(X):
    x1 = X[:, 0]
    x2 = X[:, 1]

    return np.column_stack([
        x1,        # original first input
        x2,        # original second input
        x1 ** 2,   # squared first input
        x1 * x2,   # interaction between the inputs
        x2 ** 2    # squared second input
    ])

The two original features let the boundary tilt or shift. The squared terms add curvature, and the product lets the two inputs interact. As in the preceding implementation, the classifier keeps its bias separately.

X_phi = polynomial_features(X)

model = LogisticRegression(
    learning_rate=0.01,
    epochs=1000
)

model.fit(X_phi, y)

Before prediction, transform new observations in exactly the same way:

X_new_phi = polynomial_features(X_new)
predictions = model.predict(X_new_phi)
important

The transformation used during training must also be used during prediction. If the model was trained on $(x_1,x_2,x_1^2,x_1x_2,x_2^2)$, every new observation must be represented by those same five features in the same order.

Exercise 2.4.1 — Build a nonlinear classifier

Use the circular dataset from this note. Fit logistic regression using only $x_1$ and $x_2$, then inspect its boundary. Add $x_1^2+x_2^2$ as a feature, fit the classifier again, and compare the predictions and boundaries. Why can the transformed model separate the classes? Is the classifier linear in feature space, and is its boundary linear in the original input space? If you like, extend the transformation to the complete degree-2 polynomial basis.

Next steps

Basis functions let a simple model represent nonlinear relationships, but we still have to choose the transformation ourselves. Later in the course, neural networks will learn useful nonlinear representations directly from data.
