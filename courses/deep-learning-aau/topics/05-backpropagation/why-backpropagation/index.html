Why do we need backpropagation.

Why efficient gradient calculation is needed to train a neural network.

What this note covers

  • Predictions, gradients and updates
  • Two directions of computation

Predictions, gradients and updates

In the neural networks notes, we evaluated a network by passing an input through a sequence of layers. To train it, we also need to know how its loss changes when each parameter changes. Write the mean loss on fixed training data as $L(\boldsymbol{\theta})$, where $\boldsymbol{\theta}$ collects all weights and biases. If there are $P$ parameters, the gradient contains one partial derivative for each parameter:

$$\nabla_{\boldsymbol{\theta}} L(\boldsymbol{\theta})=\left(\frac{\partial L}{\partial \theta_1},\ldots,\frac{\partial L}{\partial \theta_P}\right)^\top.$$

Each component measures the local change in loss for a small change to that parameter, with the others held fixed. As discussed in gradient descent, an update uses these derivatives to move in a direction that locally decreases the loss:

$$\boldsymbol{\theta}_{t+1}=\boldsymbol{\theta}_{t}-\eta\nabla_{\boldsymbol{\theta}} L(\boldsymbol{\theta}_{t}),$$

where $\eta$ is the learning rate and $t$ is the update number. But a parameter in an early layer influences the loss through every subsequent transformation. How can we calculate all of these derivatives without repeating the same work?

Two directions of computation

During forward propagation, each layer uses its inputs and parameters to calculate its output. The prediction and target then determine the loss. During backpropagation, we start from that loss and propagate derivatives backwards, combining them with the intermediate values already calculated in the forward pass.

Different parameters share many of the same downstream calculations. Backpropagation reuses the derivative of the loss with respect to an intermediate value wherever it is needed, instead of independently retracing the network for every parameter. For an ordinary feed-forward network, this makes the cost of the full gradient comparable to the cost of evaluating the network.

Gradient calculation and optimisation are different steps. Backpropagation calculates derivatives; it does not change parameters. Gradient descent or another optimiser uses those derivatives to make an update.

The mathematical tool behind this reuse is the chain rule. We begin with a single composition and then look at what happens when a value influences the loss along more than one path.
