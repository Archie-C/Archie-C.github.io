A complete worked example.

Calculate a forward pass and every gradient in a small network.

What this note covers

  • The network
  • Forward propagation
  • Backward propagation
  • All parameter gradients
  • One update

The network

We will calculate all the gradients for one training example. Let the input, target and parameters be

$$\mathbf{x}=\begin{pmatrix}1\\2\end{pmatrix},\qquad y=0.5,$$
$$\mathbf{W}^{(1)}=\begin{pmatrix}0.5&0\\0&0.5\end{pmatrix},\qquad \mathbf{b}^{(1)}=\begin{pmatrix}0\\0\end{pmatrix},$$
$$\mathbf{W}^{(2)}=\begin{pmatrix}1&-1\end{pmatrix},\qquad b^{(2)}=0.$$

The two hidden units use $\tanh$, the output is linear, and the single-example loss is $L=\ell(\hat{y},y)=\frac12(\hat{y}-y)^2$. The zero weights are still trainable. We show six decimal places below, but retain full precision between calculations.

Forward propagation

The hidden pre-activations and activations are

$$\mathbf{z}^{(1)}=\mathbf{W}^{(1)}\mathbf{x}+\mathbf{b}^{(1)}=\begin{pmatrix}0.5(1)+0(2)\\0(1)+0.5(2)\end{pmatrix}=\begin{pmatrix}0.5\\1\end{pmatrix},$$
$$\mathbf{a}^{(1)}=\tanh(\mathbf{z}^{(1)})=\begin{pmatrix}0.462117\\0.761594\end{pmatrix}.$$

The output layer and loss are therefore

$$\hat{y}=z^{(2)}=\begin{pmatrix}1&-1\end{pmatrix}\mathbf{a}^{(1)}+0=0.462117-0.761594=-0.299477,$$
$$L=\frac12(-0.299477-0.5)^2=0.319582.$$

Backward propagation

Because the output activation is the identity, its signal is

$$\delta^{(2)}=\frac{\partial L}{\partial \hat{y}}\frac{\partial \hat{y}}{\partial z^{(2)}}=(\hat{y}-y)(1)=-0.799477.$$

For the hidden layer, $\tanh'(z)=1-\tanh^2(z)$. The two signals are

$$\begin{aligned}\delta_1^{(1)}&=(1-0.462117^2)(1)(-0.799477)=-0.628747,\\\delta_2^{(1)}&=(1-0.761594^2)(-1)(-0.799477)=0.335760.\end{aligned}$$

The negative output weight reverses the sign of the contribution to the second hidden signal. The matrix form is $\boldsymbol\delta^{(1)}=((\mathbf W^{(2)})^\top\delta^{(2)})\odot(1-(\mathbf a^{(1)})^2)$, with the square taken elementwise.

All parameter gradients

For the output layer, each weight gradient is the output signal times its hidden activation:

$$\frac{\partial L}{\partial\mathbf W^{(2)}}=\delta^{(2)}(\mathbf a^{(1)})^\top=\begin{pmatrix}-0.799477(0.462117)&-0.799477(0.761594)\end{pmatrix}=\begin{pmatrix}-0.369452&-0.608877\end{pmatrix},\qquad \frac{\partial L}{\partial b^{(2)}}=-0.799477.$$

For the hidden layer, the outer product with the input gives every weight gradient, including those at zero-valued weights:

$$\frac{\partial L}{\partial\mathbf W^{(1)}}=\begin{pmatrix}-0.628747\\0.335760\end{pmatrix}\begin{pmatrix}1&2\end{pmatrix}=\begin{pmatrix}-0.628747&-1.257494\\0.335760&0.671520\end{pmatrix},\qquad \frac{\partial L}{\partial\mathbf b^{(1)}}=\begin{pmatrix}-0.628747\\0.335760\end{pmatrix}.$$

Consider the initially zero weight $w_{12}^{(1)}$. Its source activation is $x_2=2$ and its receiving signal is $\delta_1^{(1)}=-0.628747$, so its gradient is approximately $-1.257494$. The weight happens to be zero at this point, but a small change to it still changes the first hidden pre-activation. Conversely, if this input were zero, the corresponding weight gradient would be zero for this example even if the error signal were nonzero.

The dimensions provide a useful independent check. The hidden signal has shape $2\times1$, the input transpose has shape $1\times2$, and their outer product has shape $2\times2$, matching $\mathbf W^{(1)}$. For the output layer, the scalar signal multiplied by the $1\times2$ hidden activation transpose gives the required $1\times2$ gradient.

One update

Using learning rate $\eta=0.1$, subtract $0.1$ times each gradient from its parameter. This gives, to six places,

$$\mathbf W^{(1)}_{\rm new}=\begin{pmatrix}0.562875&0.125749\\-0.033576&0.432848\end{pmatrix},\quad \mathbf b^{(1)}_{\rm new}=\begin{pmatrix}0.062875\\-0.033576\end{pmatrix},$$
$$\mathbf W^{(2)}_{\rm new}=\begin{pmatrix}1.036945&-0.939112\end{pmatrix},\quad b^{(2)}_{\rm new}=0.079948.$$

Using the unrounded updated parameters, another forward pass gives $\hat{y}_{\rm new}\approx 0.188194$ and $L_{\rm new}\approx 0.048612$, lower than the original loss for this example. This decrease is a result of this particular step, not a guarantee for an arbitrary learning rate. A negative gradient means that a small increase in that parameter decreases the loss locally; a positive gradient indicates the opposite. All updates use gradients evaluated at the same original parameters. Larger networks use the same operations, arranged as matrix computations. Next we check these derivatives independently.
