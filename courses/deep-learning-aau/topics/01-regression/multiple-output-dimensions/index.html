Multiple Output Dimensions.

Now we want to predict more than one target variable.

What this note covers

  • The model
  • The objective function

For a more formal definition, see Deep learning: Foundations and Concepts

The model

In the previous note, we used several input features to predict one target. Now suppose each example has $m$ target values. For one example, the target and prediction are vectors in $\mathbb R^m$:

$$\mathbf y=\begin{pmatrix}y_1\\\vdots\\y_m\end{pmatrix},\qquad \hat{\mathbf y}=\begin{pmatrix}\hat y_1\\\vdots\\\hat y_m\end{pmatrix}.$$

For each output we need its own weights and bias. As in the previous note, append a one to the input to form $\tilde{\mathbf x}=(1,x_1,\ldots,x_d)^\top$. Put the bias and input weights for output $k$ in row $k$ of an augmented matrix:

$$\widetilde{\mathbf W}=\begin{pmatrix}b_1&w_{11}&\cdots&w_{1d}\\b_2&w_{21}&\cdots&w_{2d}\\\vdots&\vdots&\ddots&\vdots\\b_m&w_{m1}&\cdots&w_{md}\end{pmatrix}\in\mathbb R^{m\times(d+1)},\qquad \hat{\mathbf y}=\widetilde{\mathbf W}\tilde{\mathbf x}.$$

The entry $w_{kj}$ connects input feature $j$ to output $k$. Without the augmented input, the same expression is $\hat{\mathbf y}=\mathbf W\mathbf x+\mathbf b$, with $\mathbf W\in\mathbb R^{m\times d}$ and $\mathbf b\in\mathbb R^m$. This row-per-output convention is also used for neural-network layers.

For $n$ examples, stack the target vectors as rows of $\mathbf Y\in\mathbb R^{n\times m}$ and the augmented inputs as rows of $\tilde{\mathbf X}\in\mathbb R^{n\times(d+1)}$. The prediction matrix is $\hat{\mathbf Y}=\tilde{\mathbf X}\widetilde{\mathbf W}^{\top}$.

The objective function

We can sum the squared errors for every observation and output, or divide that sum by $n$ for the mean over observations. The two objectives have the same minimiser. If $\tilde{\mathbf X}$ has full column rank, solving the least-squares equations gives

$$\widetilde{\mathbf W}^{\top}=(\tilde{\mathbf X}^{\top}\tilde{\mathbf X})^{-1}\tilde{\mathbf X}^{\top}\mathbf Y.$$

Each column of the right-hand side solves the same least-squares problem for one output. If the design matrix is rank deficient, the displayed inverse does not exist; a pseudoinverse or another suitable solver can be used instead.
