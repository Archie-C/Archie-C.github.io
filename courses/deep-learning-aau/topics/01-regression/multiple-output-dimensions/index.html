Multiple Output Dimensions.

Now we want to predict more than one target variable.

What this note covers

  • The model
  • The objective function

For a more formal definition, see Deep learning: Foundations and Concepts

The model

In the previous section (multiple input dimensions), we extended the linear regression model to handle multiple input features. Now we extend it further to handle multiple targets too.

We can write a target vector for a single data point as:

$$ \mathbf{y} = \begin{bmatrix} y_1 \\ y_2 \\ \vdots \\ y_l \end{bmatrix} $$

where $l$ is the number of target variables. To predict this vector, we can use a weight matrix instead of a weight vector:

$$ \mathbf{\Theta} = \begin{bmatrix} w_{01} & w_{02} & \cdots & w_{0l} \\ w_{11} & w_{12} & \cdots & w_{1l} \\ \vdots & \vdots & \ddots & \vdots \\ w_{n1} & w_{n2} & \cdots & w_{nl} \end{bmatrix} $$

Here, $w_{ij}$ represents the weight connecting the $i$-th input feature to the $j$-th target variable.

We can also use the same trick as before and create a target matrix that covers all data points:

$$ \mathbf{Y} = \begin{bmatrix} y_{11} & y_{12} & \cdots & y_{1l} \\ y_{21} & y_{22} & \cdots & y_{2l} \\ \vdots & \vdots & \ddots & \vdots \\ y_{m1} & y_{m2} & \cdots & y_{ml} \end{bmatrix} $$

Again, $m$ is the number of data points and $l$ is the number of target variables.

The objective function

Luckily, the rest of the formulation is the same as before so we can write the closed-form solution for the optimal weights as:

$$ \mathbf{\Theta} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{Y} $$

important

I won't go through the implementation details as it is pretty much the same as the single output case. If you are interested in trying yourself, this synthetic dataset would be a good start.
