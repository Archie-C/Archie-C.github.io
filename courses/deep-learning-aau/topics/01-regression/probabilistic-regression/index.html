Regression as probabilistic modelling.

Why does squared error make sense as a loss function?

What this note covers

  • Adding observation noise to a regression model
  • Fitting the model with maximum likelihood
  • How Gaussian noise leads to squared error

In the earlier notes, squared error measured how far a prediction was from its target. This extra note gives it a probabilistic interpretation: fitting a regression function can also mean fitting a distribution of possible target values.

Adding noise to the prediction

Think back to the height and age example. Students of the same age do not all have the same height. A regression line gives a useful prediction, but it cannot describe that variation on its own.

We can write the prediction for an input $\mathbf{x}$ as $y(\mathbf{x},\mathbf{w})$, where $\mathbf{w}$ contains the model parameters. For a single continuous target $t$, suppose the observation is this prediction plus some noise:

$$ t = y(\mathbf{x},\mathbf{w}) + \epsilon, \qquad \epsilon \sim \mathcal{N}(0,\sigma^2). $$

The noise has mean zero and variance $\sigma^2$. Adding it to the prediction gives a Gaussian distribution centred on that prediction:

$$ p(t\mid\mathbf{x},\mathbf{w},\sigma^2) = \mathcal{N}\!\left(t\mid y(\mathbf{x},\mathbf{w}),\sigma^2\right). $$

So $y(\mathbf{x},\mathbf{w})$ is the conditional mean: which is the average value the model predicts for this input. The standard deviation $\sigma$ describes how widely observations vary around it. This works for a linear regression function, a polynomial, or a neural network.

The likelihood of the data

Now suppose there are $N$ observed input–target pairs, $\mathcal{D}=\{(\mathbf{x}_n,t_n)\}_{n=1}^{N}$. Assume the targets are conditionally independent given their inputs and the model parameters. The joint density is then the product of their individual densities:

$$ p(\mathbf{t}\mid\mathbf{X},\mathbf{w},\sigma^2) = \prod_{n=1}^{N}\mathcal{N}\!\left(t_n\mid y(\mathbf{x}_n,\mathbf{w}),\sigma^2\right). $$

Once the data are observed, hold them fixed and treat this expression as a function of $\mathbf{w}$. This is the likelihood of the targets given the data and the model parameters. Maximum likelihood chooses the weights that maximise this likelihood. For now, we will keep $\sigma^2$ fixed too.

density and likelihood

The same expression has two uses. With the parameters fixed, it describes the density of possible targets for different inputs. With the data fixed, it compares parameter choices. A likelihood is not a probability distribution over the weights.

From likelihood to squared error

If we write $\hat{t}_n=y(\mathbf{x}_n,\mathbf{w})$ as the prediction of target $t_n$. The Gaussian density for one observation is:

$$ p(t_n\mid\mathbf{x}_n,\mathbf{w},\sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\!\left(-\frac{(t_n-\hat{t}_n)^2}{2\sigma^2}\right). $$

If we take the logarithm of this expression, we get:

$$ \log p(t_n\mid\mathbf{x}_n,\mathbf{w},\sigma^2) = -\frac{1}{2}\log(2\pi\sigma^2) -\frac{(t_n-\hat{t}_n)^2}{2\sigma^2}. $$

A nice property of the logarithm is that it turns the product for the whole dataset into a sum. Also, negating it gives the negative log likelihood, which we can use as an objective function to minimise:

$$ \begin{aligned} -\log p(\mathbf{t}\mid\mathbf{X},\mathbf{w},\sigma^2) &= -\sum_{n=1}^{N}\log p(t_n\mid\mathbf{x}_n,\mathbf{w},\sigma^2) \\ &= \frac{1}{2\sigma^2}\sum_{n=1}^{N}(t_n-\hat{t}_n)^2 \\ &\quad + \frac{N}{2}\log(2\pi\sigma^2). \end{aligned} $$

With $\sigma^2$ fixed, the last term is constant with respect to the weights. The factor $1/(2\sigma^2)$ is positive, so it changes the scale of the objective without changing its minimum. We can remove the constant term and the factor $1/(2\sigma^2)$, and still get the same optimum. So, this leaves the same squared-error problem as before:

$$ \mathbf{w}_{\mathrm{ML}} = \arg\min_{\mathbf{w}}\; \frac{1}{2}\sum_{n=1}^{N}\left(\hat{t}_n-t_n\right)^2. $$

We leave the factor $1/2$ in the objective function for convenience when taking derivatives. Dividing the sum by $N$ to use mean squared error also gives the same optimum.

A small example

Suppose the observed targets are $1$, $2$, and $3$, and the model predicts the same value $\mu$ for all three. Keep $\sigma=1$. Moving $\mu$ changes both the likelihood and the squared error:

fig 2–3 The likelihood peaks and squared error reaches its minimum at $\mu=2$, the mean of the targets. Each dot marks this same fit. The curves use different vertical scales.

For this example, the negative log likelihood is $\frac{1}{2}\sum_n(t_n-\mu)^2+\frac{3}{2}\log(2\pi)$. It is the squared-error curve shifted upwards by a constant, so its minimum stays at $\mu=2$.

The assumptions behind the loss

The derivation depends on the observation model:

  1. Gaussian noise. Each target has a Gaussian distribution around the prediction, making the prediction its conditional mean.
  2. Constant variance. The same $\sigma^2$ applies at every input. This is called homoscedastic noise.
  3. Conditional independence. Given the inputs and parameters, the target densities multiply.

A continuous target lets you use a density, but it does not guarantee Gaussian noise is a good assumption. If the spread changes with the input, a single fixed variance will miss that pattern.

A different noise model can also give a different loss. For example, Laplace noise with fixed scale leads to absolute error rather than squared error.

what if the variance is learned?

If $\sigma^2$ is also a parameter to fit, the normalising term depends on it and must stay in the objective. With a separate variance at each input, the residuals receive different weights too.

What does a prediction tell you?

A point prediction reports the conditional mean. The Gaussian observation model also describes the spread of possible targets around it. With fitted weights and a known noise standard deviation, about 95% of that distribution lies within $y(\mathbf{x},\mathbf{w})\pm1.96\sigma$.

This spread describes observation noise with the weights held fixed. It does not account for uncertainty about the fitted weights themselves.

key takeaway

Minimising squared error is equivalent to maximum likelihood under independent Gaussian observation noise with fixed variance. The regression function predicts the mean; the noise model describes the variation around it.
