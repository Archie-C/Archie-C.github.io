    Question 3*

    Let X ∈ ℝn × (d + 1) be the input matrix (n samples, d features + a bias term), y ∈ ℝn be the output vector and θ ∈ ℝd + 1 be the weight vector.

    1. Derive the OLS solution that minimises the residual sum of squares ‖y − Xθ‖2.
    2. Under what conditions does this solution fail?
    3. Name one practical fix for the above condition and explain why.
