Why deep networks?

We can make a neural network wider by adding neurons, or deeper by adding hidden layers. Here we look at why adding layers can be useful and what the trade-offs are.

What this note covers

  • Width and depth
  • Universal approximation
  • Learning and reusing features
  • The benefits and costs of adding layers

Shallow and deep networks

In the neural networks note, we introduced a hidden layer whose neurons each calculate a weighted sum of the inputs and apply an activation function. We then combine their outputs to make a prediction. This gave us a way to learn the basis functions instead of choosing them ourselves.

Now suppose this network is not powerful enough for our problem. We could add more neurons to the hidden layer, or we could add another hidden layer. Adding neurons increases the width; adding layers increases the depth. We call a network with one hidden layer shallow, and one with several hidden layers deep.

With more layers, the calculation in each layer is the same as before:

$$\mathbf{z}^{(\ell)}=h^{(\ell)}\!\left(\mathbf{W}^{(\ell)}\mathbf{z}^{(\ell-1)}+\mathbf{b}^{(\ell)}\right), \qquad \mathbf{z}^{(0)}=\mathbf{x}.$$

Here $\mathbf{W}^{(\ell)}$ and $\mathbf{b}^{(\ell)}$ are the weights and biases for layer $\ell$, and $h^{(\ell)}$ is its activation function. The difference is that the inputs are now the outputs of the previous layer, rather than the original input features.

So we apply one function, then apply another function to its result, and so on. This is called function composition. If we write each layer as $f_\ell$, the complete network is:

$$f(\mathbf{x})=f_L\bigl(f_{L-1}(\cdots f_1(\mathbf{x}))\bigr).$$

Here $L$ includes the output layer. As we saw in the activation functions note, we need nonlinear activations for this to give us more than an affine transformation. Each new layer can then learn combinations of the features calculated by the previous layer.

Universal approximation

Before we look at why extra layers help, it is useful to know what we can do with just one hidden layer. It turns out that, if we make it wide enough, we can approximate any continuous function on a compact domain using a suitable activation function and a linear output. This is the universal approximation theorem. Sigmoid and ReLU are suitable choices, although not every nonlinear activation has this property.

There are a couple of terms to unpack here. A continuous function has no jumps. In the input spaces we use here, a compact domain is a closed and bounded set, such as the interval $[0,1]$, including its endpoints.

By approximate, we mean that we can make the network output as close to the function as we like. For example, suppose we want the error to be less than $0.01$ everywhere on $[0,1]$. The theorem tells us that a sufficiently wide network with suitable weights exists. We can ask for a smaller error too, but we may need more neurons and different weights.

important

This tells us that suitable weights exist. It does not tell us how to find them, how many neurons we need, or how well a network fitted to a dataset will predict on unseen data. It also does not say that one hidden layer uses the fewest parameters.

The function we want to approximate is $g(x)=0.55\sin(2\pi x)+0.3x$. With $M$ neurons, first choose evenly spaced input values $t_j=j/M$, for $j=0,\ldots,M$. The slope between each pair of neighbouring points is:

$$s_j=\frac{g(t_{j+1})-g(t_j)}{t_{j+1}-t_j},\qquad j=0,\ldots,M-1.$$

Now we use one ReLU to give us the first slope, and another at each interior point to change the slope. This gives:

$$y_M(x)=g(0)+s_0\operatorname{ReLU}(x) +\sum_{j=1}^{M-1}(s_j-s_{j-1})\operatorname{ReLU}(x-t_j).$$

So we have $M$ hidden neurons with input weights $1$ and biases $0$ or $-t_j$. Their output weights are the changes in slope. On $[0,1]$, this joins the chosen points with straight lines.

Why add more layers?

If one hidden layer can approximate the function, why bother adding more? The issue is how many neurons and parameters we need to do it. Being able to represent a function does not mean we have found an efficient way to represent it.

For example, suppose we have four inputs. One neuron compares $x_1$ and $x_2$, while another checks whether $x_3+x_4$ exceeds $1$. We can pass both results to the next layer and combine them in different ways:

We calculate $u$ and $v$ once, then use them in both of the later calculations. A function built using smaller functions like this has a compositional structure. A deep network can follow that structure, with each layer doing part of the calculation.

For some functions, doing this needs substantially fewer neurons than a shallow network would need for the same accuracy. If it also needs fewer weights and biases, we have better parameter efficiency. This is one reason depth can be useful. Mhaskar, Liao and Poggio (2016) give results for particular classes of compositional functions.

The small example above shows how we can reuse a calculation; it does not establish a parameter saving. Adding layers is not always more efficient. That depends on the function we are trying to learn and the widths and connections we choose.

Hierarchical representations

Let's consider a more familiar example: recognising handwritten digits. The input is just a collection of pixel values, but the useful information is in the shapes those pixels make. A loop, for example, could help us recognise a zero, a six, or an eight.

An early layer could learn to respond to edges and curves. A later layer could combine those into a loop, and another could combine two loops into part of an eight. We call this a hierarchical representation: later layers combine simpler features into features that describe larger parts or patterns in the image.

This builds on the basis functions we used in nonlinear regression. There we chose the transformation ourselves, for example by adding $x^2$ as a feature. With a neural network, we learn the transformation. With several layers, we can also learn new features using the features we have already learned.

The vector $\mathbf{z}^{(\ell)}(\mathbf{x})$ is therefore a learned representation of the input. It contains the outputs of the neurons in layer $\ell$. The next layer works with these values instead of the original pixels, so the representation needs to keep the information useful for the task.

Distributed representations and feature reuse

So far we have talked about features such as edges and loops, but this does not mean that each one must correspond to a single neuron. Information can be spread across the values of several neurons. This is called a distributed representation.

We can also use the same feature for several different digits. A curved edge could help identify a zero, a three, or an eight. Straight edges and intersections are useful for other digits, depending on where they occur:

Some features that can be useful for more than one digit
Feature responseCan contribute toWhat else matters?
Curved edges0, 3, 8Whether curves close into loops, and where they occur
Straight edges1, 4, 7Stroke direction, position, and combination
Intersections4, crossed 7Which strokes meet and how they are arranged

This means we do not need to learn every possible digit pattern independently. We can learn some useful features and combine them in different ways. A neuron in a later layer might use an earlier feature with one weight, while another neuron uses the same feature with a different weight.

These are examples of how we might interpret the learned features. A curve may be represented by several neurons, and any one of those neurons may also contribute to other features. We will look at learned representations in more detail in the Representation Learning note.

Does deeper always mean better?

As with adding more basis functions in regression, we should not assume that a more complex model will give better predictions. There are some costs to adding layers:

  • We have more calculations to perform, with each layer waiting for the outputs of the previous one.
  • We may have more weights and biases to store, as well as the intermediate neuron outputs. Using narrower layers can reduce some of this cost.
  • Finding suitable weights can be harder because changing one layer affects the calculations in later layers.
  • The choice of widths, activations, initial weights, and training settings can affect whether the extra layers help.

During training, information about the error must pass through the layers to adjust the earlier weights. The gradients involved can become very small or very large. These are called vanishing and exploding gradients, and we will cover them later.

There are four separate things to consider when comparing two networks:

Four things to consider when comparing networks
ConceptQuestion
Representational capacityWhich functions can the network express or approximate?
Parameter efficiencyHow many weights and biases are needed for a given accuracy?
OptimisationCan training find useful values for those parameters?
GeneralisationHow well does the fitted model predict on unseen examples?

In the regularisation note, we saw that fitting the training data well does not guarantee good predictions on unseen data. The same applies here. We need to choose a depth that suits the problem, the amount of data we have, and the time and memory available, then check the model on held-out data.

Worked example

Now let's work through the small network shown earlier. We have four inputs $x_1,x_2,x_3,x_4$ and use ReLU, $h(a)=\max(0,a)$, in both hidden layers. First, we calculate two features:

$$u=h(x_1-x_2),\qquad v=h(x_3+x_4-1).$$

For $u$, the weights are $1$ and $-1$, with no bias. For $v$, both weights are $1$ and the bias is $-1$. So $u$ is positive when $x_1>x_2$, and $v$ is positive when $x_3+x_4>1$.

Next, we use these two values as the inputs to another layer:

$$q=h(u+v-1),\qquad r=h(u-v).$$

Here $q$ adds the two features and subtracts $1$, while $r$ takes their difference. Both then apply ReLU. Finally, we combine them with a linear output:

$$y=q+2r.$$

Let's use the input $\mathbf{x}=(2,0,2,1)^\top$. The first layer gives:

$$u=\max(0,2-0)=2,\qquad v=\max(0,2+1-1)=2.$$

Substituting these into the second layer:

$$q=\max(0,2+2-1)=3,\qquad r=\max(0,2-2)=0.$$

And the prediction is:

$$y=3+2(0)=3.$$

So the first layer gives us $(u,v)=(2,2)$, and the second gives $(q,r)=(3,0)$. We used both $u$ and $v$ twice without calculating them again. This is function composition and feature reuse. A shallow network could also approximate the same function; the example shows how the deeper calculation is organised.

Summary

Adding layers allows us to learn new features using the outputs of earlier layers. For some problems, this uses fewer parameters than one very wide layer. But we still need to find suitable weights and check that the model generalises; depth alone does not guarantee either. How we construct and train the network matters.
