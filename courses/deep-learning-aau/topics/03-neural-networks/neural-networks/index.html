Neurons, weights, and biases

We ended the previous note by introducing parameters to the basis functions such that our regression model now looks like this:

$$y(\mathbf{x}, \mathbf{w}, \boldsymbol{\theta}) = w_0 + \sum_{j=1}^M w_j \phi_j(\mathbf{x}; \theta_j)$$

Now we need a way to express this parameterisation. A common way to do this is to use an artificial neuron. The neuron takes a vector of inputs, multiplies each input by a weight, adds a bias term and then applies an activation function. Mathematically, we can express this as:

$$\phi_j(\mathbf{x}; \theta_j) = h(\mathbf{a}_j^{\top} \mathbf{x} + b_j) $$

Here $\mathbf{a}_j$ is the vector of weights applied to the inputs, $b_j$ is the bias term, and $h$ is the activation function. Together, $\mathbf{a}_j$ and $b_j$ make up the neuron's parameters $\theta_j$. I will call the weighted input, including the bias, $s_j = \mathbf{a}_j^\top\mathbf{x} + b_j$.

We will explore different types of activation functions and their applications in the next note. For now, we will use the rectified linear unit (ReLU) as the activation function.

The ReLU function is defined as:

$$h(a) = \max(0, a) = \begin{cases} a & \text{if } a \geq 0 \\ 0 & \text{if } a < 0 \end{cases}$$

Here $a$ is a scalar argument to the function, such as the weighted input $s_j$. ReLU keeps positive values and replaces negative values with zero.

Layers and network architecture

A single neuron gives us one single learnable feature. However, just as we used multiple basis functions in regression, we can construct multiple neurons to learn different features from the same input.

Suppose we construct $M$ neurons, each with its own weights and bias. The output of neuron $j$ is:

$$ \phi_j(\mathbf{x}; \theta_j) = h(\mathbf{a}_j^\top \mathbf{x} + b_j) $$

When multiple neurons are arranged in parallel, we call the collection a layer. More specifically, a layer that lies between the input and final prediction is called a hidden layer.

The output of the layer is a vector of features, which we can express as:

$$ \boldsymbol{\phi}(\mathbf{x}) = \begin{bmatrix} \phi_1(\mathbf{x}) \\ \phi_2(\mathbf{x}) \\ \vdots \\ \phi_M(\mathbf{x}) \end{bmatrix} $$

Building a complete network

Now we have $M$ learned features. But we still need to combine these to produce a prediction.

Fortunately, it turns out it's the same as before: we can use a linear combination of these features to produce a prediction:

$$ y(\mathbf{x}) = w_0 + \sum_{j=1}^{M} w_j \phi_j(\mathbf{x}) $$

Note, for brevity I omit the $\theta$.

The difference now is that the features $\phi_j$ are learned from the data, rather than being fixed basis functions. And substituting their definition gives:

$$ y(\mathbf{x}) = w_0 + \sum_{j=1}^{M} w_j h(\mathbf{a}_j^\top \mathbf{x} + b_j) $$

We can use this construction for different tasks. For regression, the final output is a real number. For binary classification, we can apply a sigmoid function to the final linear combinations:

$$ p(C_1 \mid \mathbf{x}) = \sigma\left( w_0 + \sum_{j=1}^{M} w_j h(\mathbf{a}_j^\top \mathbf{x} + b_j) \right) $$

Matrix representation

When we have lots of neurons and layers, writing out each neuron becomes cumbersome. Instead, we can express an entire layer using matrix multiplication.

Suppose our input has $D$ features and we have $M$ neurons in the layer. We can represent the weights of the layer as a matrix $\mathbf{A} \in \mathbb{R}^{M \times D}$ :

$$ \mathbf{A} = \begin{bmatrix} \mathbf{a}_1^\top \\ \mathbf{a}_2^\top \\ \vdots \\ \mathbf{a}_M^\top \end{bmatrix} $$

where each row corresponds to the weights of a neuron. Similarly, we can collect their biases into a vector:

$$ \mathbf{b} = \begin{bmatrix} b_1 \\ b_2 \\ \vdots \\ b_M \end{bmatrix} $$

And now the output of the layer is simply:

$$ \boldsymbol{\phi}(\mathbf{x}) = h(\mathbf{A}\mathbf{x} + \mathbf{b}) $$

Where the activation function $h$ is applied separately to each element of the vector.

In vector form the final prediction can be written as:

$$ y(\mathbf{x}) = w_0 + \mathbf{w}^\top \boldsymbol{\phi}(\mathbf{x}) $$

And if we combine these expressions, we get the full neural network model for a network with $D$ inputs, $M$ hidden neurons, and a single output:

$$ \boxed{ y(\mathbf{x}) = w_0 + \mathbf{w}^\top h(\mathbf{A}\mathbf{x} + \mathbf{b}) } $$

Worked example: forward propagation

Calculating a prediction by passing an input through the network, layer by layer, is called a forward pass, or forward propagation. At each neuron, you multiply the inputs by their weights, sum the results with the bias, and apply the activation function. The resulting values become the inputs to the next layer.

Consider a regression network with two input features, two hidden neurons using ReLU, and one output neuron. The output neuron takes a weighted sum of the hidden features and adds a bias, just as in the model above. Its activation is the identity function, which simply returns its input. For this example, the weights and biases are already given.

Take the input and hidden-layer parameters to be:

$$ \mathbf{x} = \begin{bmatrix}2\\1\end{bmatrix},\qquad \mathbf{A} = \begin{bmatrix}1 & 1\\-1 & 1\end{bmatrix},\qquad \mathbf{b} = \begin{bmatrix}-1\\0\end{bmatrix}. $$

The first row of $\mathbf{A}$ gives $\mathbf{a}_1^\top = [1,1]$, and the second gives $\mathbf{a}_2^\top = [-1,1]$. The weights that combine the hidden features are $\mathbf{w} = [2,-1]^\top$, with output bias $w_0 = 1$. These output weights play a different role from the weights inside $\mathbf{A}$.

Step 1: calculate the hidden weighted inputs

For the first neuron, multiply each input by its corresponding weight and add $b_1$:

$$s_1 = \mathbf{a}_1^\top\mathbf{x} + b_1 = 1\cdot 2 + 1\cdot 1 - 1 = 2.$$

The second neuron uses the same inputs but its own weights and bias:

$$s_2 = \mathbf{a}_2^\top\mathbf{x} + b_2 = (-1)\cdot 2 + 1\cdot 1 + 0 = -1.$$

These are the values before applying the activation function. In matrix form, the same calculation is:

$$ \mathbf{A}\mathbf{x} + \mathbf{b} = \begin{bmatrix}1 & 1\\-1 & 1\end{bmatrix} \begin{bmatrix}2\\1\end{bmatrix} + \begin{bmatrix}-1\\0\end{bmatrix} = \begin{bmatrix}3\\-1\end{bmatrix} + \begin{bmatrix}-1\\0\end{bmatrix} = \begin{bmatrix}2\\-1\end{bmatrix}. $$

Step 2: apply ReLU

Apply $h(a) = \max(0,a)$ separately to each weighted input:

$$\phi_1(\mathbf{x}) = \max(0,2) = 2,\qquad \phi_2(\mathbf{x}) = \max(0,-1) = 0.$$

The first neuron's positive value passes through unchanged. The second neuron's negative value becomes zero. The hidden layer has therefore turned the input into the feature vector $\boldsymbol{\phi}(\mathbf{x}) = [2,0]^\top$.

Step 3: calculate the output

Finally, combine these two features using the output weights and bias:

$$ \begin{aligned} y(\mathbf{x}) &= w_0 + w_1\phi_1(\mathbf{x}) + w_2\phi_2(\mathbf{x})\\ &= 1 + 2\cdot 2 + (-1)\cdot 0\\ &= 1 + 4 + 0 = 5. \end{aligned} $$

The second hidden neuron contributes zero for this input, even though its output weight is $-1$. The output activation is the identity, so the final prediction is $5$. This completes one forward pass.

Number of parameters

Increasing the number of neurons increases the number of parameters in the model. This can increase the model's capacity to learn complex functions, but also increases the risk of overfitting and the computational cost of training. How many parameters does a particular architecture have?

In a fully connected layer, every neuron receives every output of the previous layer. If there are $n_{\mathrm{in}}$ inputs and $n_{\mathrm{out}}$ neurons, each neuron has $n_{\mathrm{in}}$ weights and one bias. The layer therefore has:

$$P_{\mathrm{layer}} = \underbrace{n_{\mathrm{out}}n_{\mathrm{in}}}_{\text{weights}} + \underbrace{n_{\mathrm{out}}}_{\text{biases}} = n_{\mathrm{out}}(n_{\mathrm{in}}+1).$$

For a network with $D$ inputs, one hidden layer of $M$ neurons, and $K$ output neurons, apply this count to each layer. The hidden layer contains $MD$ weights in $\mathbf{A}$ and $M$ biases in $\mathbf{b}$. Each output neuron receives all $M$ hidden features, so the output layer contains $KM$ weights and $K$ biases. Adding the two counts gives:

$$\boxed{P = MD + M + KM + K = M(D+1) + K(M+1).}$$

With a single output, the output-layer parameters are precisely $w_1,\ldots,w_M$ and $w_0$ from the earlier equations. For multiple outputs, each output neuron has its own set of these parameters. The input values and intermediate neuron outputs are calculated values, so they do not add any parameters. ReLU itself has no parameters.

In the worked example, $D=2$, $M=2$, and $K=1$. The hidden layer has $2\cdot 2=4$ weights and $2$ biases. The output layer has $1\cdot 2=2$ weights and $1$ bias. Therefore:

$$P = 2(2+1) + 1(2+1) = 6 + 3 = 9.$$

The zero bias $b_2$ still counts: it is a parameter whose current value happens to be zero. Similarly, a hidden neuron producing zero for one input does not remove any parameters.

Deeper networks

So far, the hidden layer has taken the original input features and produced a new feature vector. There is no reason to stop there: the outputs of one hidden layer can become the inputs of another hidden layer. Each neuron in the next layer applies its own weights, bias, and activation to those values.

The width of a layer is its number of neurons. Different hidden layers can have different widths, so it is often useful to state the width of each one. The depth describes how many layers are composed in sequence. Here I count layers with weights and biases, including the output layer but excluding the input. Under this convention, the network in the worked example has depth $2$: one hidden layer and one output layer.

To describe this for any number of layers, let $\mathbf{z}^{(\ell)}$ be the vector of outputs from layer $\ell$. Define $\mathbf{z}^{(0)} = \mathbf{x}$, so the original input is the starting point. Then each layer can be written as:

$$\boxed{ \mathbf{z}^{(\ell)} = h^{(\ell)}\left( \mathbf{W}^{(\ell)}\mathbf{z}^{(\ell-1)} + \mathbf{b}^{(\ell)} \right). }$$

Here the superscript $(\ell)$ labels a layer; it is not a power. The vector $\mathbf{z}^{(\ell-1)}$ contains the outputs of the preceding layer. The matrix $\mathbf{W}^{(\ell)}$ contains the current layer's weights, with one row per neuron, and $\mathbf{b}^{(\ell)}$ contains its biases. The activation $h^{(\ell)}$ is then applied to each element to produce $\mathbf{z}^{(\ell)}$. Different layers may use different activation functions.

If the preceding layer has $n_{\ell-1}$ outputs and the current layer has $n_\ell$ neurons, then $\mathbf{W}^{(\ell)}\in\mathbb{R}^{n_\ell\times n_{\ell-1}}$ and $\mathbf{b}^{(\ell)}\in\mathbb{R}^{n_\ell}$. The resulting $\mathbf{z}^{(\ell)}$ has $n_\ell$ components, ready to serve as the inputs to the next layer. For the last layer $L$, $\mathbf{z}^{(L)}$ is the network's prediction.

This is the same construction as before, with notation that labels each layer. In the worked example, $\mathbf{W}^{(1)}=\mathbf{A}$, $\mathbf{b}^{(1)}=\mathbf{b}$, and $\mathbf{z}^{(1)}=\boldsymbol{\phi}(\mathbf{x})$. The second layer has $\mathbf{W}^{(2)}=\mathbf{w}^\top$ and a single bias $w_0$. Using the identity activation at this output layer recovers $y(\mathbf{x})=w_0+\mathbf{w}^\top\boldsymbol{\phi}(\mathbf{x})$.

A deeper network repeats this calculation through more hidden layers. The reasons for choosing greater depth will be covered in a later note. First, there is a more basic question: why apply a nonlinear activation between layers at all?

Why do we need nonlinear activation functions?

Consider removing the nonlinear activations, so every layer simply returns its weighted input plus bias. A map of the form $\mathbf{W}\mathbf{x}+\mathbf{b}$ is called an affine transformation: a linear transformation followed by a translation. If the bias is zero, it is a linear transformation.

For two layers without nonlinear activations, the equations become:

$$ \begin{aligned} \mathbf{z}^{(1)} &= \mathbf{W}^{(1)}\mathbf{x} + \mathbf{b}^{(1)},\\ \mathbf{z}^{(2)} &= \mathbf{W}^{(2)}\mathbf{z}^{(1)} + \mathbf{b}^{(2)}. \end{aligned} $$

Substitute the first expression into the second and expand:

$$ \begin{aligned} \mathbf{z}^{(2)} &= \mathbf{W}^{(2)}\left(\mathbf{W}^{(1)}\mathbf{x}+\mathbf{b}^{(1)}\right) +\mathbf{b}^{(2)}\\ &= \mathbf{W}^{(2)}\mathbf{W}^{(1)}\mathbf{x} +\mathbf{W}^{(2)}\mathbf{b}^{(1)}+\mathbf{b}^{(2)}\\ &= \widetilde{\mathbf{W}}\mathbf{x}+\widetilde{\mathbf{b}}, \end{aligned} $$

where:

$$\widetilde{\mathbf{W}}=\mathbf{W}^{(2)}\mathbf{W}^{(1)},\qquad \widetilde{\mathbf{b}}=\mathbf{W}^{(2)}\mathbf{b}^{(1)}+\mathbf{b}^{(2)}.$$

These two layers are therefore equivalent to a single affine transformation. Adding a third affine layer gives another affine transformation by exactly the same calculation, and this argument can be repeated for any number of layers. More affine layers alone cannot make the network represent a nonlinear relationship. With one input and one output, its prediction is still a straight line, so it cannot, for example, equal $y=x^2$ for every real $x$.

A nonlinear activation changes this. With ReLU, whether a neuron's weighted input passes through or becomes zero depends on the input itself. In general, you can no longer combine the whole network into one fixed weight matrix and bias vector. This allows the network to represent nonlinear relationships, even when its final output layer is affine, as in the worked example.
