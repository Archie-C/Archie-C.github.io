Neural networks exercises 2026

Exercises in preparation for building, training, and evaluating neural networks.

  1. 01

    Question 1

    Consider a neural network with two inputs, two ReLU hidden neurons and one linear output:

    $$\mathbf{z} = W^{(1)}\mathbf{x} + \mathbf{b}^{(1)}, \qquad \mathbf{h} = \operatorname{ReLU}(\mathbf{z}), \qquad y = W^{(2)}\mathbf{h} + b^{(2)}.$$

    For $\mathbf{x} = \begin{pmatrix} 1 \\ 2 \end{pmatrix}$, use

    $$W^{(1)} = \begin{pmatrix} 1 & -1 \\ 2 & 1 \end{pmatrix}, \quad \mathbf{b}^{(1)} = \begin{pmatrix} 0 \\ -1 \end{pmatrix}, \quad W^{(2)} = \begin{pmatrix} 2 & -1 \end{pmatrix}, \quad b^{(2)} = 1.$$

    1. Calculate the network output $y$, showing $\mathbf{z}$ and $\mathbf{h}$.
    2. Calculate the total number of trainable parameters.
    3. Recalculate the output if the hidden neurons use identity activations instead of ReLU.
    4. For the ReLU network, compute the gradients of $y$ with respect to $W^{(1)}$ and $\mathbf{b}^{(1)}$ at this input.
    5. Using your answer to the previous part, state how a gradient descent step on this input changes the parameters of the first hidden neuron. Name the problem that arises if the same holds for every training input.
  2. 02

    Question 2

    A neural network controls a rocket by predicting continuous thrust $T \in [0, T_{\max}]$ and gimbal angle $g \in [-g_{\max}, g_{\max}]$. It is trained by supervised learning on expert demonstrations.

    1. How many output neurons are required? Explain whether softmax is appropriate for these outputs.
    2. Suggest an output activation or transformation for each output that enforces its control limits. State one drawback of your choice when the best control lies at a limit, such as full thrust.
    3. What problems can arise when ordinary mean squared error is applied to outputs with very different scales? Propose a solution.
    4. Why might a model with low prediction error on expert demonstrations still fail to land successfully in closed-loop control?
  3. 03

    Question 3*

    Consider a single-hidden-layer network with scalar input and output:

    $$f(x) = b + \sum_{j=1}^{M} v_j h(w_j x + b_j).$$

    1. Prove that if $h$ is the identity activation, the network reduces to an affine function $f(x) = ax + c$. Give $a$ and $c$ in terms of the parameters.
    2. Find weights and biases for a ReLU network with $M = 2$ that represents $f(x) = |x|$ exactly.
    3. Prove that no function of the form $ax + c$ equals $|x|$ for all real $x$.
    4. Show that with ReLU activations, $f$ is piecewise linear with at most $M + 1$ linear pieces.
    5. The universal approximation theorem says one hidden layer can approximate any continuous function on a compact set. Using the previous part, explain why this does not make deep networks unnecessary.
    6. Does universal approximation guarantee that training will find a good approximation? Explain.
