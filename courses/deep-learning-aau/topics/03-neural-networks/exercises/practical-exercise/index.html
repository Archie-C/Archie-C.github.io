Practical exercise 2026: Rocket Control

Build a neural network controller to guide a rocket to a safe landing.

Task

practical exercise

Implement a neural network regression controller that predicts two normalized control values: thrust in [0, 1] and gimbal angle in [-1, 1].

Your Python file must define a Controller class with predict_action(observation). Return a two-element sequence (thrust, gimbal) for each observation. The simulator calls this method every 0.1 seconds.

Upload a self-contained controller or upload saved weights as well. With a weights file, the class must implement load(path). The controller is evaluated in your browser on validation flights; no training data is currently provided.

See the physics behind the simulation for more detail.

Run a controller

Evaluation runs in your browser. Upload a controller and, optionally, its saved model weights.

Return (thrust, gimbal) with thrust from 0 (engine off) to 1 and gimbal from -1 to 1. The gimbal is normalized to the simulator’s maximum angle; positive is leftward thrust deflection.
