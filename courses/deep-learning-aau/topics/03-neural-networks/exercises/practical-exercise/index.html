Practical exercise 2026: Rocket Control

Build a neural network controller to guide a rocket to a safe landing.

Task

practical exercise

Implement a neural network regression controller that predicts two normalized control values: thrust in [0, 1] and gimbal angle in [-1, 1].

Submit a model.py file defining create_model() and matching weights.safetensors. Your model is evaluated on simulated landing flights and receives observations every 0.1 seconds.

Start with the training notebook, controller scaffold, and training dataset. Keep the three files in the same folder and run the notebook to train and export a basic model.

See the physics behind the simulation for more detail.

Model inputs and outputs

Each observation contains these 12 values in the order shown:

ColumnMeaningUnits
xHorizontal position relative to the pad centrem
yCentre-of-mass height relative to the padm
vx, vyHorizontal and vertical velocity; upward is positivem/s
theta, omegaTilt and angular velocity; anticlockwise is positiverad, rad/s
fuel_massRemaining fuelkg
actual_thrust, actual_gimbalCurrent engine thrust and gimbal angleN, rad
wind_x, wind_yHorizontal and vertical wind velocitym/s
air_densityAir density at the rocketkg/m³

Return (thrust, gimbal) with thrust from 0 (engine off) to 1 and gimbal from -1 to 1. The gimbal is normalized to the simulator’s maximum angle; positive is leftward thrust deflection.

Submit a PyTorch model

Submit both files for asynchronous evaluation. Your previous attempts remain available.

For this submission, model.py must expose create_model(), returning a PyTorch module. It receives a batch of 12 raw observations and returns thrust and gimbal as a two-column tensor. Include any normalization in the model; save its state as weights.safetensors.

Train and export the starter model

Download the notebook, scaffold, and dataset to the same folder. Install PyTorch, safetensors, NumPy, pandas, matplotlib and Jupyter, then run the notebook. Its final cell saves model.py and weights.safetensors for this form.

The scaffold includes a small network and its normalization. If you change its architecture, retrain the model and export matching files.
