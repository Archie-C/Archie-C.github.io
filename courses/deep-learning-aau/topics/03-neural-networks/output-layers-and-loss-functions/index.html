Outputs and loss functions.

The output of a neural network needs to suit the task. Here we look at how to make predictions and measure their errors using the regression and classification losses we already know.

What this note covers

  • Output layers for regression and classification
  • Squared error and cross-entropy losses
  • Multiclass and multilabel targets
  • Calculating losses using logits

The output layer

In the previous notes we looked at how the hidden layers calculate features of the input. Now we need to combine those features to make a prediction and decide how to measure the error. This depends on the task. Predicting a house price needs a different kind of output from predicting whether an email is spam.

First, we calculate a weighted sum of the last hidden layer's outputs and add a bias, just as we did in the other layers:

$$\mathbf{a}^{(L)}=\mathbf{W}^{(L)}\mathbf{z}^{(L-1)}+\mathbf{b}^{(L)}.$$

Here $\mathbf{z}^{(L-1)}$ contains the hidden features, and $\mathbf{W}^{(L)}$ and $\mathbf{b}^{(L)}$ are the final weights and biases. We call the resulting values output pre-activations, or usually logits when we are doing classification. Importantly, here we have not yet applied an output activation.

We can keep the same hidden architecture for regression or classification. Much of the difference is in what we do with these final values and which loss function we use:

I use $y_n$ for the true target, $\hat{y}_n$ for a regression prediction, and $p_n$ for a predicted probability. In the earlier classification notes these were written as $t_n$ for the target and $y_n$ for the probability. Here $N$ is the number of data points, and $\log$ means the natural logarithm.

Regression

Suppose we want to predict a house price using the property's features. We need one number as the prediction, so we use one output neuron. Here $\mathbf{a}^{(L)}$ has just one component, $a_1^{(L)}$: the weighted sum of the last hidden layer's outputs plus the output bias. For an unrestricted real-valued output, we can return this value unchanged:

$$\hat{y}=a_1^{(L)}=\sum_j W_{1j}^{(L)}z_j^{(L-1)}+b_1^{(L)}.$$

This is called an identity activation. It puts no restriction on the output, so it can also return a negative number. For house prices this is a limitation of the unconstrained model.

To measure the error, we can use the same squared error as in linear regression. Taking the mean over our data points gives mean squared error:

$$\mathcal{L}_{\mathrm{MSE}}=\frac{1}{N}\sum_{n=1}^{N}(y_n-\hat{y}_n)^2.$$

Squaring means that larger errors receive a larger penalty. If we double an error, its contribution to the loss becomes four times as large.

As we saw in probabilistic regression, minimising this loss gives the maximum likelihood prediction parameters if we assume independent Gaussian noise with constant variance. Using MSE does not itself make that assumption true. Mean absolute error, $\frac{1}{N}\sum_n|y_n-\hat{y}_n|$, is another option.

So adding hidden layers changes how we construct the prediction, but we can still use the regression losses we already know.

Binary classification

Now suppose we want to classify an email as spam or not spam. We write the target as $y=1$ for spam and $y=0$ for not spam. Again we need just one output neuron, but this time we want a probability. Like before in logistic regression, we apply sigmoid:

$$p(C_1\mid\mathbf{x})=\sigma(a_1^{(L)}).$$

This gives a value between zero and one, which we interpret as the probability of spam. If we write $p_n=p(C_1\mid\mathbf{x}_n)$, the mean binary cross-entropy loss is:

$$\mathcal{L}_{\mathrm{BCE}}=-\frac{1}{N}\sum_{n=1}^{N} \left[y_n\log p_n+(1-y_n)\log(1-p_n)\right].$$

This is the negative log-likelihood of a Bernoulli model, averaged over the data points. We derived it in the classification notes. The calculation is the same here; we are just using learned hidden features to calculate the score instead of using the original inputs directly.

Let's take one email that is actually spam, so $y=1$. The second term disappears and the loss is $-\log p$. Substituting three different probabilities gives:

Loss for one positive target

$0.90$Confident and correct$-\log(0.90)\approx0.105$

To make a class decision, we can choose spam when $p\geq0.5$. But we do not apply this threshold before calculating the loss. For example, $p=0.4$ and $p=0.01$ both give the decision not spam, but BCE tells us that the second is a much worse prediction for a spam email.

Multiclass classification

For handwritten digit recognition, there are ten possible classes and exactly one is correct. This is multiclass classification. As with binary classification, the classes are mutually exclusive, but now there are more than two.

We use one output neuron for each class. For $K$ classes, this gives a vector of scores:

$$\mathbf{a}^{(L)}\in\mathbb{R}^{K}.$$

We could apply sigmoid to each score, but then several outputs could be close to one. They would not necessarily add up to one, which we need for a distribution over mutually exclusive classes. Instead, we use softmax. Dropping the layer superscript for brevity:

$$p_k=\frac{\exp(a_k)}{\sum_{j=1}^{K}\exp(a_j)}.$$

First we exponentiate each score, making it positive, then divide by the total. So every probability is positive and their sum is one:

$$p_k>0,\qquad \sum_{k=1}^{K}p_k= \frac{\sum_{k=1}^{K}\exp(a_k)}{\sum_{j=1}^{K}\exp(a_j)}=1.$$

For a small example, suppose the scores for three classes are $(2,1,0)$. Their exponentials are approximately $(7.389,2.718,1)$. Adding these gives $11.107$, so the probabilities are:

$$\mathbf{p}\approx\left(\frac{7.389}{11.107},\frac{2.718}{11.107}, \frac{1}{11.107}\right)=(0.665,0.245,0.090).$$

We normally choose the class with the highest probability, which here is class 1. This is also the class with the highest original score. Below we can compare what sigmoid and softmax do to the same scores:

Now we need to write the targets in a form that matches these outputs. We use a vector with a one for the correct class and zeros for the others. For example, if class 2 is correct, $\mathbf{y}=(0,1,0)$. This is called one-hot encoding.

The corresponding loss is categorical cross-entropy, averaged over the data points:

$$\mathcal{L}_{\mathrm{CE}}=-\frac{1}{N}\sum_{n=1}^{N} \sum_{k=1}^{K}y_{nk}\log p_{nk}.$$

For each data point, all the target values except one are zero. So only the probability of the correct class contributes to the loss. If the correct class is $c_n$, this is just $-\log p_{n,c_n}$. Like the binary case, we get this loss by taking the negative log-likelihood, this time using a categorical distribution.

Multilabel classification

Suppose instead we want to identify what is present in a photograph. It could contain a dog, a person, and a bicycle at the same time. We cannot treat these as mutually exclusive classes. This is multilabel classification, where several labels can be correct for the same input.

Softmax would force the probabilities to share a total of one. Here we want to allow high probabilities for several labels, so we apply sigmoid separately to each score:

$$p_k=\sigma(a_k).$$

With scores $(2,1,0)$ we get approximately $(0.881,0.731,0.500)$, which does not sum to one. The target could be $(1,1,0)$ if the photograph contains a dog and a person, but no bicycle. Unlike the one-hot target, it can contain more than one one.

We calculate BCE for each label. With $K$ labels and $N$ data points, we can average over both:

$$\mathcal{L}_{\mathrm{ML}}=-\frac{1}{NK}\sum_{n=1}^{N}\sum_{k=1}^{K} \left[y_{nk}\log p_{nk}+(1-y_{nk})\log(1-p_{nk})\right].$$

This models the labels as conditionally independent Bernoulli variables given the input. They still use the same hidden features, so their predicted probabilities can change together across photographs. For example, a feature could raise both the dog and person probabilities. We are not modelling any dependence left between the label outcomes once the input is fixed.

Logits, probabilities and numerical stability

So far we have written the output activation and loss as separate steps. In practice, libraries often combine them. The reason is that calculating the probabilities first can cause numerical problems.

For example, exponentiating a large score can produce a number too large for the computer to store. A calculated probability can also round to exactly zero or one, leaving us trying to take the logarithm of zero in the loss.

Instead, we can calculate the loss using the original logits:

  • BCE with logits combines sigmoid and BCE in one calculation.
  • Softmax cross-entropy using logits calculates the categorical loss without first storing the probabilities and then taking their logarithms.

The mathematical losses are the same. We have just rearranged the calculations to avoid numerical problems. You can see examples in the documentation for BCE with logits and multiclass cross-entropy.

One useful rearrangement is the log-sum-exp trick. First, subtract the largest score, $m=\max_j a_j$, before exponentiating. Then all the exponentials are at most one. We account for the subtraction outside the logarithm:

$$\log\sum_j e^{a_j}=m+\log\sum_j e^{a_j-m}.$$

This is why a model may return raw scores during training even when we interpret its predictions as probabilities. If the loss expects logits, pass it the logits directly. We can apply sigmoid or softmax separately when we want to inspect the probabilities.

Choosing the output and loss

We can now put the common choices together. The first thing to decide is what the target represents, then choose an output and loss that suit it:

Common output layers and losses

Multiclass: one of K classes$K$SoftmaxCategorical CEClass probabilities summing to 1

These are common choices, rather than rules for every possible model. The activation may also be included in the loss calculation, as we just discussed.

A loss function is the objective we use to fit the model. An evaluation metric tells us how it performs. For example, accuracy counts correct class decisions, but ignores how confident the model was. It also does not give us a useful differentiable objective for learning the weights. So we can report accuracy while still using cross-entropy as the training loss.

Worked example

Let's take a network whose last hidden layer has eight neurons, so $\mathbf{z}^{(L-1)}\in\mathbb{R}^{8}$. We can use the same hidden architecture for three different tasks by changing the output layer and loss.

Each output neuron needs eight weights, one for each hidden value, and a bias. So the final weight matrix has eight columns and one row for each output:

Example scores and predictions for one input
TaskFinal weights and biasRaw scoresPrediction
One continuous value$\mathbf{W}^{(L)}\in\mathbb{R}^{1\times8}$, $\mathbf{b}^{(L)}\in\mathbb{R}^{1}$$2.5$$\hat{y}=2.5$
One of three classes$\mathbf{W}^{(L)}\in\mathbb{R}^{3\times8}$, $\mathbf{b}^{(L)}\in\mathbb{R}^{3}$$(2,1,0)$$(0.665,0.245,0.090)$; choose class 1
Three binary labels$\mathbf{W}^{(L)}\in\mathbb{R}^{3\times8}$, $\mathbf{b}^{(L)}\in\mathbb{R}^{3}$$(2,1,0)$$(0.881,0.731,0.500)$; interpret each label separately

First, suppose we are predicting one continuous value and the output is $2.5$. If the true target is $y=3$, we subtract the prediction and square the error:

$$\mathcal{L}_{\mathrm{MSE}}=(3-2.5)^2=0.25.$$

Now suppose we are choosing one of three classes. The scores $(2,1,0)$ give us the softmax probabilities calculated earlier. If class 2 is correct, we take the negative logarithm of its probability. Using the unrounded value:

$$\mathcal{L}_{\mathrm{CE}}=-\log\left(\frac{e^1}{e^2+e^1+e^0}\right)\approx1.408.$$

Finally, suppose the three outputs are separate binary labels and the target is $(1,1,0)$. We use sigmoid and take a binary loss for each label, then average them:

$$\begin{aligned} \mathcal{L}_{\mathrm{ML}}&=-\frac{1}{3} \left[\log\sigma(2)+\log\sigma(1)+\log(1-\sigma(0))\right]\\ &\approx\frac{0.127+0.313+0.693}{3}\approx0.378. \end{aligned}$$

The last two output layers have the same shape, but their probabilities mean different things and we use different losses. We can keep the hidden architecture the same; training it on different tasks will generally change the hidden weights too.

Summary

The hidden layers calculate features, and the output layer uses them to make a prediction. We choose its activation according to what we want to predict, and use a loss function to measure how good the predictions are. For classification, it is often better to calculate that loss directly using logits for numerical stability.
