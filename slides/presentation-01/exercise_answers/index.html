  1. 01

    Question 1

    What tasks would you solve with linear regression? When would it not be suitable?

    The answer to this depends somewhat on the notation used. Generally, linear regression is any regression model that is linear in the parameters. However, it is also reasonable to define linear regression as a model that models only linear relationships between input and output features and define the case that uses basis functions as linear regression with non-linear basis functions.

    Using the first case, any task that is either a linear relationship or can be transformed reasonably into a linear relationship can be solved with linear regression.

    It is not suitable for tasks that are inherently non-linear and cannot be transformed into a linear relationship, or for tasks where the assumptions of linear regression (such as homoscedasticity, independence of errors, and normality of errors) are violated. Additionally, in its basic form, linear regression is not suitable for classification tasks, as it predicts continuous values rather than discrete classes.

    Question 2

    Use the ten survey observations of age and weekly exercise to fit and interpret a linear regression model.

    1. Fit the model.

      Minimise the sum of squared errors:

      $$ \hat{y}_i = mx_i + c, \qquad L(m,c) = \sum_{i=1}^{n} (y_i - mx_i - c)^2. $$

      Set both partial derivatives to zero:

      $$ \begin{aligned} \frac{\partial L}{\partial m} &= -2\sum_i x_i(y_i-mx_i-c)=0, \\ \frac{\partial L}{\partial c} &= -2\sum_i (y_i-mx_i-c)=0. \end{aligned} $$

      Writing $\bar{x}=\frac{1}{n}\sum_i x_i$ and $\bar{y}=\frac{1}{n}\sum_i y_i$, the second equation gives:

      $$ \sum_i y_i-m\sum_i x_i-nc=0 \quad\Rightarrow\quad c=\bar{y}-m\bar{x}. $$

      Substitute into the first equation:

      $$ \begin{aligned} \sum_i x_i y_i-m\sum_i x_i^2-(\bar{y}-m\bar{x})\sum_i x_i &=0, \\ m\left(\sum_i x_i^2-n\bar{x}^2\right) &=\sum_i x_i y_i-n\bar{x}\bar{y}. \end{aligned} $$

      Hence:

      $$ \boxed{m=\frac{\sum_i x_i y_i-n\bar{x}\bar{y}}{\sum_i x_i^2-n\bar{x}^2} =\frac{\sum_i(x_i-\bar{x})(y_i-\bar{y})}{\sum_i(x_i-\bar{x})^2}}. $$

      This is the unique minimum when $\sum_i(x_i-\bar{x})^2>0$.

      For these data, $\bar{x}=43.6$, $\bar{y}=5.05$:

      $$ m=\frac{-245.8}{2062.4}\approx-0.11918, \qquad c=5.05-m(43.6)\approx10.24631. $$

      $$ \boxed{\hat{y}\approx-0.11918x+10.24631} $$

      Here $x$ is age in years and $\hat{y}$ is predicted exercise in hours per week.

    2. Predict for an 80-year-old.

      Substituting $x=80$ into the equation:

      $$ \hat{y}\approx-0.11918(80)+10.24631\approx-9.5344+10.24631\approx0.71191. $$

      Therefore, the model predicts that an 80-year-old will exercise approximately 0.71 hours per week.

      This is an unreasonable prediction, as it is outside the domain of the data (ages 22 - 68). Therefore, we must extrapolate. In general, extrapolation is risky as we cannot be sure that the relationship holds outside of the observed range.

    3. Discuss the limitations.

      There a number of possible answers to this question. Some require assumptions and some do not.

      The limitations that don't are:

      • We only have a small sample size of 10.
      • The survey was conducted in a specific location and may not be representative of the broader population.

      The limitations that require assumptions are:

      • We assume that the relationship is linear.
      • We assume that there are no other factors that affect the relationship.
  3. 03

    Question 3*

    Derive the OLS solution, discuss when the inverse formula fails, and explain a practical fix.

    1. Derive the solution.

      We have $X \in \mathbb{R}^{n \times (d+1)}$, $y \in \mathbb{R}^n$ and $\theta \in \mathbb{R}^{d+1}$. Which means the prediction is $\hat{y} = X\theta$. Therefore, the loss is:

      $$L(\theta) = \frac{1}{2} \| y - X\theta \|^2$$

      You can omit the constant $\frac{1}{2}$ in the derivation if you like, but it's often included for convenience.

      There are two ways to go about this. We can derive the norm directly or we can expand the norm then derive the expanding terms:

      Method 1: Expand the norm and then derive each term:

      The norm can be written as:

      $$L(\theta) = \frac{1}{2} (y - X\theta)^T (y - X\theta)$$

      Which if we expand we get:

      $$L(\theta) = \frac{1}{2} (y^T y - y^T X\theta - \theta^T X^T y + \theta^T X^T X\theta)$$

      Then as $y^T X\theta = \theta^T X^T y$ because they are both scalars and the transpose of a scalar is the scalar itself, we can simplify:

      $$L(\theta) = \frac{1}{2} (y^T y - 2\theta^T X^T y + \theta^T X^T X\theta)$$

      To find the optimal $\theta$, we take the derivative and set it to zero:

      $$\nabla_\theta L(\theta) = -X^Ty + X^T X\theta = 0$$

      Method 2: Derive the norm directly:

      $$\nabla_\theta L(\theta) = \nabla_\theta \frac{1}{2} \| y - X\theta \|^2 = \nabla_\theta \frac{1}{2} (y - X\theta)^T (y - X\theta)$$

      $$\nabla_\theta L(\theta) = -X^T(y - X\theta) = 0$$

      Both of these lead to the same result:

      $$X^T X\theta = X^T y$$

      Which are the normal equations.

      We can solve for $\theta$ by multiplying both sides by the inverse of $X^TX$:

      $$\theta = (X^TX)^{-1} X^T y$$

    2. State the failure conditions.

      The normal equations fail when the matrix $X^T X$ is singular, and therefore has no inverse.

    3. Explain a practical fix.

      There are many practical fixes:

      01: Use regularisation (e.g., Ridge regression) to make the matrix invertible.

      This is essentially adding a small value to the diagonal of the matrix which we do by adding a penalty to the loss function:

      $$L(\theta) = \frac{1}{2} \| y - X\theta \|^2 + \lambda \|\theta\|^2$$

      If you carry this through the derivation you find the normal equations become:

      $$X^T X\theta + \lambda \theta = X^T y$$

      and therefore:

      $$\theta = (X^T X + \lambda I)^{-1} X^T y$$

      The parameter $\lambda$ controls the amount of regularisation (more regularisation means larger weights are penalised more and therefore is more stable, but also can reduce the ability of the model to fit the data well).

      02: Use a pseudo-inverse such as the Moore-Penrose pseudo-inverse to solve the system of equations. (out of the scope of this course)

      03: Use a different optimisation algorithm that doesn't rely on the normal equations, such as gradient descent (this will come later in the course).

      04: Increase the number of samples to make the matrix more likely to be invertible.

      05: Use feature selection to reduce the number of features, making the matrix more likely to be invertible.

      06: Use a dimensionality reduction technique, such as Principal Component Analysis (PCA), to reduce the number of features. (out of the scope of this course)
